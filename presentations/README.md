# 발표 자료: PDF 기준

2026-10-29 사용자 지시에 따라 앞으로 발표 자료는 **PDF를 직접 제작·수정**합니다. PPTX 제작과 변환은 기본 작업에서 제외합니다.

## 최신 열람 자료

- [PDF 전용 발표 자료 v0.2](https://chatgpt.com/library?file_id=libfile_31382d5932448191a4713288046bef15&account_id=personal): 총 11페이지. 기존 발표 흐름을 유지하고 09장 다음 10장에 1안 기반 비주얼 보강 화면을 수록했습니다.
- [저장소의 비주얼 상세안 PDF](RoxHistory_Overview_v0.1.pdf): 11페이지. 10장에 통합 시안 포함.
- [인수인계 정합본 PDF](RoxHistory_Overview_v0.1-handover.pdf): 10페이지. 최신 기획 방향과 기존 상세 구상을 구분합니다.

## 제작과 확인 기준

1. 새 자료와 수정본의 최종 산출물은 PDF입니다. 별도 요청이 있을 때만 PPTX를 제작합니다.
2. 밝은 아이보리 배경, 짙은 글자, 차분한 주황색 포인트와 16:9 발표 구성을 유지합니다.
3. PDF를 렌더링해 전체 페이지의 한글, 여백, 표, 이미지, 페이지 순서와 잘림을 확인합니다.
4. 전체 비주얼은 아기자기한 2.5D 1안을 기준으로 합니다. 2안의 자연광, 배경 깊이와 사냥 동작은 같은 스타일 안에 접목합니다.
5. 통합 화면은 검토용 생성 이미지입니다. 실제 구현 화면이나 고증 승인 자료가 아니며 Figma에는 아직 추가되지 않았습니다.

## 기존 파일과 자동화

기존 PPTX, 생성 스크립트, pdf-manifest.json은 이전 작업 기록으로 보존합니다. 과거의 PPTX·PDF 동시 갱신 의무와 원본 일치 검사는 현재의 PDF 단독 제작에 적용하지 않습니다.

GitHub Actions는 PDF 열림과 페이지 유효성을 검사합니다. PPTX 자동 변환·PDF 덮어쓰기·자동 커밋은 실행하지 않습니다. 과거 변환 스크립트는 사용자가 PPTX를 별도로 요청한 경우에만 검토합니다.
