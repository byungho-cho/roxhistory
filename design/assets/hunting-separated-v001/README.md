# RoxHistory 사냥 독립 에셋 v001

이 묶음은 개발 연결과 미술 검토용입니다. 승인 화면을 배경 하나로 사용하지 않도록 환경, 전경, 사슴, UI를 독립 파일로 준비했습니다. 기존 게임 소스와 Figma 원안은 바꾸지 않았습니다.

## 바로 사용할 수 있는 파일
- `backgrounds/battle-clean-v001.png`: 1672×941. 인물·동물·HUD 없는 전체 숲 가장자리 배경. 승인 전투 시안을 참고해 가려진 영역을 새로 복원했습니다. 정확한 원본 추출이 아닙니다.
- `foreground/hunters-foliage-group-v001.png`: 1662×946 RGBA. 사냥꾼 3명과 전경 식생을 하나의 이동 그룹으로 새로 그린 투명 이미지입니다. 원안 인물과 완전히 동일한 픽셀/얼굴을 보장하지 않습니다.
- `../../../game/assets/animals/deer-rigged.glb`: 저장소의 기존 실제 사슴 모델을 그대로 사용합니다. 이 폴더에는 중복 복사하지 않았습니다. 15본, 16,000 삼각형, 애니메이션 클립 0개입니다.
- `actors/deer-front-left.png`, `deer-side-left.png`: 실제 GLB의 1536×1536 투명 정지 렌더. 임의로 만든 다른 사슴 그림이 아닙니다.
- `ui/*.svg`: 텍스트와 수치를 굽지 않은 독립 벡터 20개. 같은 이름의 2배 크기 RGBA PNG가 `ui/png-2x/`에 있습니다.

## 품질과 승인 상태
- 배경과 전경의 실제 해상도는 위 숫자이며, 4K나 네이티브 2K로 납품한 것이 아닙니다. 저해상도 원안을 확대해 고해상도라고 표기하지 않았습니다.
- SVG는 해상도 독립적입니다. 그러나 원안의 회화적 나무·양피지 장식을 단순화해 다시 그린 디자인입니다. 기능 연결용으로 사용할 수 있지만, 원안과 동급의 최종 미술 승인본은 아닙니다.
- 사슴 PNG에는 스튜디오 조명이 들어 있습니다. 게임에서는 GLB를 직접 조명하는 것을 권장합니다. 기존 모델의 표면 요철/텍스처 이음새를 그대로 보존했습니다.
- 사슴의 idle/run/hit/death/flee 애니메이션은 없습니다. 새 모델을 먼저 구매할 필요는 없고, 기존 리그에 해당 동작을 추가하고 스킨 변형을 검증하는 것이 다음 단계입니다.
- 준비용 별도 고해상도 클린 배경, 원안 수준의 회화적 UI, 개별 주민 초상은 이 묶음에 포함되지 않습니다. 전경 사냥꾼은 편성 변경에 따라 바뀌지 않는 하나의 이미지입니다.

## 레이어와 전환
`transition-layers.json`은 레이어 계약입니다. 준비 타이틀, 전경 숲+사냥꾼, 우측 팝업, 사슴을 별도 노드로 둡니다. 배경 전체를 항상 가장 아래에 깔고, 이 네 그룹만 움직입니다. 전경이 나갈 때 비어 있던 곳이 보이지 않도록 배경을 패널 뒤까지 채워야 합니다.

준비 요소 퇴장 → 배경 전환 → 전투 컨트롤·타이틀·상태바 진입 순서입니다. 전투 상태바는 캐릭터/몬스터 위치를 추적하고 전경에 합치지 않습니다. 약 0.8초 전환은 기획의 제안이며 확정 상수로 굽지 않습니다. 클릭 차단, 화면 크기 대응, 연타, 취소, 앱 복귀 상태를 개발에서 검증해야 합니다.

SVG의 글씨, 사슴 이름, 체력, 비용, 충전 수치는 Godot Label/ProgressBar로 올립니다. 반원 충전은 `charge-semicircle-track.svg` 위에 런타임 각도/길이로 그립니다. 공격 비용이나 능력 이름을 이 에셋에서 결정하지 않습니다.
