# 농장 빈 밭 + 곡식 성장 분리본 v003

PR #67의 `v002/farm-l*.png`에는 곡식이 포함되어 있습니다. 이 폴더는 성장 연출용으로 빈 밭 4종과 공통 곡식 4단계를 분리한 후속 자산입니다. 기존 게임 코드 및 개발 브랜치는 수정하지 않았습니다.

## 구성

- `farm-empty-l1~l4.png`: **곡식 없는** 흙·외곽·울타리·허수아비. RGBA 투명 배경.
- `grain-growth-01~04.png`: 기존 승인 성장 스프라이트를 변경 없이 복사. 580×580, 모든 단계가 같은 뿌리 기준점 (290, 530.7)을 공유합니다.
- `manifest.json`: 이미지 크기/체크섬, 사용자 Figma 크기 비율, 합성용 정규화 작물 위치.
- `preview.html`: 로컬 HTTP 서버에서 열 수 있는 단계별 조합 예제.
- `preview-0/1/4.png`: 같은 배치 좌표로 빈 밭·새싹·성숙을 합성한 확인 이미지(게임 캡처 아님).

## 바로 적용하는 방법

1. 성장 및 준비 기간 모두 해당 레벨의 `farm-empty-l*.png`를 배경으로 사용합니다. **v002의 곡식 포함 외형과 섞어 쓰지 않습니다.**
2. 그 위에 동일한 성장 스프라이트를 여러 개 배치합니다. 네 단계 모두 580×580 전체 캔버스 크기를 유지하고 `crop_root_anchor=[0.5,0.915]`로 뿌리를 고정합니다. 알파 영역을 단계별로 따로 잘라 크기를 맞추면 식물이 흔들립니다.
3. `levels[].crop_anchors`는 밭 표시 박스의 정규화 x/y 좌표입니다. `crop_canvas_width_fraction`은 전체 스프라이트 캔버스 폭/밭 폭 비율입니다. 단계가 바뀌어도 배치와 크기는 고정하고 텍스처만 교체합니다.
4. 작물은 y 오름차순으로 그립니다. 기본 예제는 작물을 울타리 안쪽에 배치해 앞 울타리 침범을 줄였습니다. 울타리 자체는 별도 전경 레이어가 아닙니다. 작물 크기/위치를 크게 바꿀 경우 가림 관계를 다시 확인해야 합니다.
5. `reference_display_size`는 사용자가 조절한 Figma 비율(420×320, 440×340, 480×380, 520×420)입니다. 실제 게임 월드 크기·점유 칸은 기존 개발 규칙을 유지합니다. 생성 이미지 해상도를 월드 크기로 쓰지 않습니다.
6. 준비/완전 수확 상태에는 곡식을 숨기고 빈 밭만 보여줍니다. 수확 중 남은 작물 표현은 게임의 단계별 1/2/3/4회 수확 상태에 맞춰 별도 제어합니다.

## 외형 출처와 한계

빈 밭은 최신 승인 원화(v002, L3 뒤 두 면·L4 사방 울타리 및 허수아비)에서 imagegen으로 곡식을 제거하고 가려진 흙을 **생성 복원**했습니다. 단순 픽셀 추출이 아니므로 흙무늬·고랑 수·울타리의 세부 선과 비율이 원화와 완전히 동일하지는 않습니다. 외형 방향을 유지한 개발 조합 검토본이며 최종 사용자 시각 확인은 별도입니다. L4의 잘린 허수아비 상단을 보완했습니다.

이미지 자체의 알파, 곡식 제거, 같은 위치에서 4단계 교체 가능 여부를 확인했습니다. 실제 게임 적용/빌드/게임 플레이 확인은 개발 담당 작업입니다. 미리보기의 식물 개수는 시각 배치용이며 생산량 5/10/24/40 또는 수확 횟수를 의미하지 않습니다.

생성 프롬프트: 최신 각 레벨 원화를 편집 대상으로 두고, 내부 곡식만 제거·가려진 고랑 복원, 외곽/울타리/허수아비/원근/색상 유지, 투명 배경을 요청했습니다. L4는 전체 허수아비가 보이도록 여백 보완을 추가했습니다. 성장 4장은 새로 생성하지 않았습니다.
