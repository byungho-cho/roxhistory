# 출처·권리·제한

## 출처

- 기준 파일: 사용자 RoxHistory Figma `zkbflw9fCdAlWbphhw5pSS`, 준비 `2265:75`, 전투 `2319:340`, 종료 확인 `2337:1123`.
- 모든 PNG는 이 파일의 최종 요소를 임시 복제하여 `contentsOnly: true`로 내보냈습니다. 에셋 보드의 어두운 배경을 이미지에 합성한 초기 검사 파일은 납품에서 제외했습니다. 버튼 문구는 복제본에서만 숨겨 런타임 텍스트를 분리했습니다. 원본 디자인은 바꾸지 않았습니다.
- 창·3인 협동 아이콘은 사용자 요청으로 AI 생성/리터치한 원화를 사용합니다. 기존 통짜 버튼의 완벽한 픽셀 분해본이 아닙니다. 돌망치는 기존 Figma `92:144`를 재사용했습니다.
- 스킬 배경은 기존 금색 테두리 이미지와 Figma 내부 색·광채를 조합한 래스터입니다. 스킬 효과·구슬·편성 셀·카드 프레임·교체·AUTO/X2는 Figma 벡터에서 직접 내보냈습니다.
- 배경·초상 아틀라스는 기존 편성 개발 커밋의 원본 bytes를 재사용합니다. 출처 commit과 SHA-256은 manifest에 있습니다.
- 기존 GLB는 사용자 제공 Meshy/기존 프로젝트 자산입니다. 기존 모델별 README·권리 조건을 그대로 따릅니다. 한국어 폰트는 기존 `game/assets/fonts/NotoSansKR.ttf` 및 함께 있는 OFL 문서를 사용합니다.

## 라이선스

이 인계는 새로운 공개 라이선스를 부여하지 않습니다. 저장소에 일반 root LICENSE가 확인되지 않았으며, Figma 원화·공통 아이콘·AI 원화·Meshy 모델의 외부 재배포/상용 이용 조건을 별도로 법률 검증하지 않았습니다. 공개 저장소에 있다는 사실만으로 자유 이용 가능하다고 판단하지 마세요. 기존 출처 표시와 권리 조건을 유지하고, 외부 배포 전에 프로젝트 소유자가 필요한 권리를 확인해야 합니다.

## 포함하지 않은 것

- 앱 구현, 병합, 릴리스, APK/EXE, 게임 저장 데이터 변경.
- 신규 GLB, 리깅, 걷기·찌르기·피격·쓰러짐 애니메이션 클립.
- 실제 효과 재생·카메라·구슬 충전·소리·자동·2배속 코드.
- 효과음 파일. ‘띵’ 소리는 기획만 있으며 음원을 만들거나 외부 라이브러리를 추가하지 않았습니다.
- 삭제된 과거 시안, 원화 전체를 붙인 가짜 UI, 편집 가능한 `.fig` 파일. 편집 원본은 위 Figma 링크에서 유지됩니다.
- 확정되지 않은 충전 시간, 피해량, 공격 간격, 확률, 보상/소모/종료 후 복귀 정책.
