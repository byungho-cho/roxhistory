## 파일
21개 아트 파일: SVG 17개(새 V/S 2, 역사 문양 3, 숫자 0–9/쉼표 11, 섬유 1), RGBA PNG 4개(단일 돌창 원본(좌우 독립 인스턴스용), 현재 사냥꾼 초상, 사슴 머리 마스크, 전투력 창 아이콘).
manifest.json: 바이트·SHA-256·논리 크기·내보내기 크기.
layout.json: 선택된 70% 헤더와 문자/문양/VS의 좌표·계층.
export-provenance.json: 정확한 Figma 원본과 렌더링 경계.

## 사용
- 전투력 헤더는 2442:1565 선택본만 사용. 숨김 보존된 60%/이전 헤더를 다시 표시하지 않습니다.
- 기존 붓터치와 공통 종이/금색·메탈 버튼은 기존 저장소 자산을 재사용합니다. 새 패치 팝업 비트맵은 필요하지 않습니다.
- 숫자는 이미지 하나가 아니라 글리프 조합. 12,300 / 8,000은 시안 예시이며 실제 데이터와 분리합니다. 기존 코드의 일부 숫자 preload만으로는 모든 값이 표시되지 않으므로 0–9 전체를 등록합니다.
- V/S/교차 돌창은 독립 레이어로 두어 순차 확대→축소 연출이 가능합니다. 논리 크기와 SVG/PNG의 렌더링 외곽 크기는 다릅니다. layout 및 manifest의 offset을 적용하고 그림자 외곽을 강제로 100×104 또는 164×164에 눌러 넣지 않습니다.
- 단일 돌창 PNG는 2배 400×400입니다. 공통 조합 164×164에서200×200으로(-18,-18)에 놓고 오른쪽 인스턴스만 수평 반전합니다. 좌우 창은 이동·회전·opacity를 독립 제어합니다. 원본 opacity0.72는 이미 PNG에 들어 있습니다.
- 사슴 머리는 현재 Figma의 마스크를 그대로 내보냈습니다. 뿔 주변에 원본 색 잔여가 있어 모든 배경에서 쓰는 완벽한 누끼 스프라이트라고 볼 수 없습니다. 해당 다크 붓터치 위 실크기로 확인하세요.
- 역사 문양 SVG 내부 opacity 0.55를 중복 적용하지 않습니다. 선택본 인스턴스의 opacity 0.75는 추가로 한 번 적용합니다. 문양·섬유는 붓터치 alpha로 함께 마스킹하며 각 문양을 개별로 켜고 끌 수 있습니다.
- 기존 전투 HP와 준비 전투력을 혼용하지 않습니다. VS만 같은 자산을 크기별로 재사용합니다.

## 검증·범위
PNG 4개 alpha/크기와 SVG 17개 XML/외부 참조를 검사했습니다. 21개 모두 Godot 4.6.3의 Image 로드에 성공했습니다. 목표 4.5.1, 게임 내 배치, APK 빌드 및 실기기 검증은 하지 않았습니다. SVG filter/그림자는 엔진에 따라 차이가 있을 수 있어 Figma와 최종 비교가 필요합니다.
이 폴더는 기존 Figma와 자산을 바꾸지 않으며 새 공개 라이선스를 부여하지 않습니다. 기존 원화·아이콘·폰트·모델의 권리와 출처 조건은 그대로 유지합니다.

## 최신 정렬과 진입 연출
준비 헤더 원점은(480,20), 초상80%/VS70%이며 layout.json의 현재 값을 사용합니다.20px는 화면 각 경계 기준이고 버튼 그림자도 포함합니다. 좌상단 제목·좌측 편성·하단 현판·우하단 버튼·AUTO/X2를 그대로 보존합니다.
사냥 준비 진입에서만 기존 구름 페이드를 대체합니다. 배경 사전 준비 → 중앙 붓터치 확대 → 양쪽 초상 순차 → 좌우 창 비행·교차와 VS 번개 → 전체 축소/상단 정착 → 나머지 UI 순차. 게임 시작/인트로 구름은 유지합니다. 상세 시간은 가안이며 전체 개발 지시문을 따릅니다. 새 돌도끼 숫자 배경은 미확정이라 포함하지 않습니다.
