# FX-001 굴뚝 연기 · 2026-11-02
정적 검토용 투명 PNG. built-in image_gen 생성. 따뜻한 회백색의 가늘고 부드러운 S자 연기, 위로 퍼지며 소멸, 배경/불꽃/굴뚝 제외.
개발: 완성된 움집 배출구 소켓에 월드 파티클을 부착. 건설 중 정지, 완료 후 재생. 천천히 상승, 약한 좌우 흔들림, 확산 및 알파 페이드. 움집별 위상 차이. 카메라 배율 연동. 지붕과 UI 가림 최소화. 화면 밖 컬링 및 앱 복귀 중복 생성 방지.
현재 애니메이션 및 게임 코드는 미구현.
