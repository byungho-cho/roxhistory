# 월드 오브젝트 2D 원화 v001
2026-11-02 KST. ENV-001 나무, ENV-002 관목, ENV-003 풀·갈대, ENV-004 바위, ANI-001 사슴, ANI-002 토끼, ANI-003 곰.
기존 원화에서 외형과 색감을 참고해 built-in image_gen으로 분리 재제작했습니다. 원화 픽셀을 그대로 잘라낸 자료는 아닙니다.
original은 생성 원본, preview는 긴 변 768px 알파 유지 축소본입니다.
동물은 향후 3D 모델링을 위한 2D 외형 참고안입니다. 다면도·리깅·애니메이션·게임 적용은 미수행.
공통 요청: 원화의 따뜻한 2.5D 그림체, 왼쪽 위 자연광, 독립된 전신/오브젝트, 투명 배경, UI·글자 제외.
동물은 의상 없는 중립 자세, 나무·관목·갈대·바위는 바닥 접점과 실루엣을 읽을 수 있는 개별 원화.
