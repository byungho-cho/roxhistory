# 사냥 준비와 전투 개발용 에셋 v006

이 폴더는 2026년 11월 10일 최신 요청을 반영한 사냥 준비와 전투 조합의 개발 입력입니다. 최신 두 화면과 독립 에셋을 연결하며, 기존 v001과 게임 코드는 변경하지 않습니다. 이전 v003 검토 ZIP보다 이 폴더를 우선합니다.

- layout의 JSON 두 개가 현재 좌표·크기·폰트·색·크롭·벡터 스타일을 담고 있습니다. 루트 프레임의 x/y는 Figma 페이지 위치이므로 게임 내부 화면 오프셋에 적용하지 않습니다.

## 최신 반영 사항
- 준비는 글자 포함 제목판과 화살표 없는 상태를 사용합니다. 목표·출전 편성·전투력 비교·준비 상태·버튼 순서 및 최신 버튼 크기를 유지합니다.
- 전투 컨트롤러는 우하단에 있습니다. 기준 프레임은 x1524, y640, 350×390이며 개별 자식의 실제 경계도 함께 확인합니다.
- 상단 중앙 숲 가장자리 제목을 복원했습니다. 제목판은 x770, y22, 412×92입니다.
- 좌상단 사냥대 텍스트를 제거하고 그 영역까지 HP 표시를 확장했습니다.
- 하단 사슴을 처치하세요 문구는 Noto Sans KR Bold 34, 흰색 채움과 갈색 외곽선을 사용합니다.
- 사슴 이름 배경은 기존 붓터치, 우상단 버튼은 기존 설정 아이콘을 재사용합니다.
- 실제 인물 3명과 사슴은 별도 레이어입니다. 인물과 사슴의 최신 크기·위치는 layout/battle.json을 그대로 기준으로 삼습니다.
- 사용자가 조정한 헤더·하단 안내판·컨트롤러 위치를 반영했습니다.

## 파일을 연결하는 방법
- preparation: 준비 클린 배경, 독립 패널, 고정 글자 포함 제목판.
- actors: 기존 모델을 렌더한 3072×3072 투명 PNG 4종. 준비와 전투 사슴은 동일 파일 하나를 참조합니다.
- battle/ui: 현재 쓰는 회화 UI 6종과 네이티브 SVG 2종.
- asset-bindings.json: 모든 현재 이미지 레이어와 실제 저장소 경로의 대응. 공통 원본의 크롭 좌표도 포함합니다.
- 공통 배경·전경·버튼·체크·붓터치·설정은 기존 파일을 참조하므로 복제하지 않았습니다.
- 사슴 이름의 왼쪽 붓터치는 가로 반전되어 있습니다. layout의 relativeTransform을 보존합니다.
- 회화 UI 6종은 이미 잘라낸 독립 PNG입니다. Figma 원본 아틀라스의 크롭을 다시 적용하지 마세요.
- HP·글자·수치·상태는 네이티브 노드로 구현하고, 스크린샷이나 인물 이미지에 합치지 않습니다.
- charge-gauge-65-reference.svg는 장식과 65% 상태의 참고입니다. 런타임 게이지는 실제 값으로 갱신합니다.
- 설정 버튼은 앞서 정한 테스트 동작인 즉시 전투 종료에 연결합니다. 실제 종료 메뉴나 게임 로직은 이 에셋 커밋에서 구현하지 않았습니다.

## 원본과 구현 한계
- 두 배경 원본은 1672×941, 전경은 1662×946입니다. 전체 에셋이 네이티브 4K라는 뜻이 아닙니다.
- 준비 전경의 사냥꾼과 식생은 합성된 한 이미지입니다. 준비 초상도 이 이미지에서 잘라 쓰므로 독립 주민 초상이나 편성 변경용 원화가 아닙니다.
- 네 모델은 무기 없는 정지 포즈이고 애니메이션 클립은 0개입니다. PNG는 화면 조합 참고이며 실제 전투에는 기존 GLB와 별도 동작 구현이 필요합니다. 원화의 창·방패 전투 자세와 차이가 남아 있습니다.
- 기존 모델의 표면·텍스처 이음새와 주민 프로토타입 상태는 보존했습니다. 출처와 해시는 actor-provenance.json에 있습니다.
- 설정 아이콘 원본은 55×55이며 현재 92×92로 표시합니다. 기존 공통 원본을 그대로 재사용한 것입니다.
- 회화 UI 원본은 1536×1024 아틀라스였으며 독립 PNG는 각 영역의 원래 크기로 내보냈습니다. 완성 화면의 확대본을 에셋으로 사용하지 않았습니다.
- HP 비율과 65/100은 화면 예시입니다. 공격 비용 10/50/100의 실행 규칙과 충전 속도는 별도 게임 기획·코드에서 관리합니다.

## 검증과 다음 단계
PNG 디코딩·알파, SVG XML, JSON, 실제 소스 해시, 기존 공통 파일 경로, 모든 이미지 레이어의 연결을 검증했습니다. 최신 Figma 화면 두 장도 비교했습니다.
이 커밋은 에셋과 기술 인계 자료만 추가합니다. Godot 연결, 이동·공격·승패, 전환 애니메이션, 화면 비율 대응, 실기기 화질·메모리·성능은 아직 검증하지 않았습니다. 게임 테스트나 빌드가 완료됐다는 의미가 아닙니다.
검증 스크립트는 Python 3와 Pillow를 사용합니다. 저장소 루트에서 python design/assets/hunting-layered-v006/validate_assets.py를 실행합니다.
