## 건설 외형 규칙 (개발 확정 요구)
- 매 건설마다 3종에서 균등 선택: 각 1/3 (약 33.333%). 33%×3으로 1%를 남기지 않습니다.
- 한 건물의 외형은 최초 생성 시 한 번만 결정하고 style_id를 저장합니다.
- 화면 재진입·저장 불러오기·건설 연출 재생 시 재추첨하지 않습니다.
- 기존 저장에 style_id가 없는 건물은 round로 유지합니다.
- 3개를 연속 건설해도 반드시 각 1종이 나오는 것은 아닙니다.
- 공통 건설 시작·진행·완료 연출, 비용 나무1·돌1, 건설2초는 유지합니다.
- 이번 커밋은 에셋/디자인 반영이며 게임 로직과 APK에는 아직 적용하지 않았습니다.
