# 업그레이드 나무 팻말·튜토리얼 손 개발 전달

## 상태와 범위
사용자가 확정한 분리 원화 시안을 개발에 사용할 수 있도록 보관한 패키지입니다. 나무 팻말은 우선 확정하고 실제 화면을 확인한 뒤 필요하면 리터치합니다.

- 에셋 원본과 이 설명만 추가합니다. 게임 코드·기존 에셋·main·배포 파일을 변경하지 않습니다.
- 원화 시안 승인과 실제 게임 적용 완료는 구분합니다. 두 이미지 모두 런타임 미연결 상태이며, 실제 표시 크기·가독성·배치·상호작용은 아직 검증하지 않았습니다.
- 원본 PNG의 픽셀, 투명 여백, 종횡비를 그대로 보존했습니다. 리사이즈·크롭·재인코딩하지 않았습니다.
- 이 전달에는 Figma 등록, 병합, 빌드 또는 배포가 포함되지 않습니다.

## 업그레이드 나무 팻말
파일: [RoxHistory_Upgrade_Wooden_Sign_v1.png](RoxHistory_Upgrade_Wooden_Sign_v1.png)

- 나무 팻말 위의 위쪽 화살표로 업그레이드를 표시하는 원화 시안입니다.
- 1265 × 1243 px, RGBA 투명 PNG입니다.
- 캔버스 해상도는 원본 보관 규격이며, 실제 게임 표시 크기가 아닙니다.
- 실제 버튼 크기에서 화살표 가독성, 투명 외곽선, 다른 아이콘과의 시각적 크기를 확인한 뒤 필요하면 리터치합니다.
- 눌림·비활성·강조 상태, 클릭 영역 및 애니메이션은 이 파일에 포함되지 않습니다.

## 45도 튜토리얼 손
파일: [RoxHistory_Tutorial_Hand_Diagonal_v2.png](RoxHistory_Tutorial_Hand_Diagonal_v2.png)

- 왼쪽 아래를 가리키는 약 45도 대각선 튜토리얼 손 원화입니다.
- 1254 × 1254 px, RGBA 투명 PNG입니다. 원본의 투명 여백과 픽셀을 그대로 유지합니다.
- 원본 캔버스 좌측 상단이 (0, 0)일 때 손끝 기준점은 약 (280, 1118)입니다. 정규화 좌표는 약 (0.2233, 0.8915)입니다.
- 목표를 가리킬 때 이미지 중앙이 아니라 이 손끝 기준점을 정렬 기준으로 사용합니다. 좌표는 초안 기준이며 실제 화면에서 오차를 확인해야 합니다.
- 비례 축소 시 같은 비율로 기준점을 변환합니다. 별도 크롭 파생본을 만들 경우 원본을 덮어쓰지 말고 크롭 오프셋만큼 기준점도 조정합니다.
- 실제 표시 크기, 손끝 정렬, 가림 여부, 튜토리얼 단계 연결 및 탭 유도 애니메이션은 아직 검증하지 않았습니다.

## 원본 및 검증
- 사용자가 이 대화에서 검토하고 확정한 생성형 이미지 원화입니다.
- PNG 디코딩, RGBA 채널, 완전 투명·불투명 픽셀 존재 및 원본 파일 해시를 확인했습니다.
- 파일 크기, SHA-256 및 Git blob SHA는 [manifest.json](manifest.json)에 기록했습니다.
- 적용 전에는 게임 화면에서 실제 크기와 여러 화면 비율을 검증해야 합니다. 이 패키지는 게임플레이 검증 결과가 아닙니다.
