## 메뉴 적용
- 5종은 메뉴 전용 그림이며 실제 게임 건축물 외형을 교체하지 않습니다. 움집·훈련소 등 기존 유지 대상은 바꾸지 않습니다.
- 원본의 종횡비를 유지하고 투명 여백을 제외한 그림 크기를 기준으로 시각적 크기·기준선을 맞춥니다. 원본 해상도를 버튼 픽셀 크기로 사용하지 않습니다.
- 아이콘과 돌판·레이블은 분리 조합합니다. 돌판 레이블 영역 중앙에 텍스트를 두며 붓터치 배경을 추가하지 않습니다.
- 건설 클릭 시 메인 메뉴를 건설 목록으로 교체. 건물 최대 5개 표시, 오른쪽 끝 건설 버튼 고정, 나머지는 가로 스크롤.
- 확정 Figma의 화살표 그래픽, 세로 구분선, 건설 선택 테두리·복귀 표시, 진한 반투명 검정 배경 및 하단 정렬을 함께 대조합니다.
- 목록 시작·우측 끝 예시에도 동일 아이콘을 사용합니다.

## 시작 화면 적용
- 가제 로고는 게임 시작 화면에만 적용합니다. RoxHistory 프로젝트명·패키지명·설치 파일명은 변경하지 않습니다.
- 최종 위치는 가로 중앙, 화면 중앙보다 위입니다. 수직 정중앙은 캐릭터를 가리므로 사용하지 않습니다.
- 로고와 배경을 분리해서 표시하고 다양한 화면 비율에서 캐릭터와 버튼을 가리지 않게 검증합니다.
- 이 패키지는 애니메이션 코드를 포함하지 않습니다.

## 원본·출처 및 검증
- 사용자가 검토·승인한 생성형 이미지 메뉴 시안 5종과 같은 프로젝트의 시작 화면 리터치 결과입니다. 외부 스톡 에셋을 새로 가져오지 않았습니다.
- 원본 PNG는 재인코딩·리사이즈 없이 복사했습니다. 각 크기, 알파 범위, 용량 및 SHA-256은 manifest.json에 기록했습니다.
- 메뉴 5종 및 로고는 RGBA 투명 PNG입니다. 배경은 RGB이며, 참고 화면은 비교 검수 전용입니다.
- 기존 배경 원화의 권리 및 가제 상표 사용 가능 여부를 이 전달 작업에서 새로 법률 검증한 것은 아닙니다. 상표 확정으로 해석하지 마세요.
