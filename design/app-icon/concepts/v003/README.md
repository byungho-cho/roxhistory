# RoxHistory 앱 아이콘 추가 시안 — v003

사용자가 선호한 **1번 영웅 얼굴**을 기준으로 만든 추가 4·5안입니다. 선사시대 → 조선 → 현대의 한국사·문명 발전을 함께 표현합니다. 기존 v001·v002 PNG는 그대로 보존합니다.

| 추가안 | 구도 | 원본 |
| --- | --- | --- |
| 4안 · 문명의 길 | 오른쪽 영웅, 왼쪽 강을 따라 움집·궁궐·현대 도시가 이어지는 밝은 구도 | [PNG](roxhistory-history-icon-04-river-of-civilization.png) |
| 5안 · 시대를 잇는 영웅 | 중앙 영웅, 황금빛 궤적과 궁궐·현대 도시를 강조한 구도 | [PNG](roxhistory-history-icon-05-golden-time-arc.png) |
