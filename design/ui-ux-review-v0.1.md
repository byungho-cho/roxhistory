# RoxHistory UI/UX 검토안 v0.1

상태: **정보 구조·화면 배치 검토안. 게임 기능 및 조작 확정 전.**

기존 4개 Figma 페이지는 보존하고 별도 검토 페이지에 1440×900 기준의 5개 화면을 작성한다. 데스크톱 크기는 비교를 위한 작업 기준이며 최종 지원 기기 결정이 아니다.

## 화면과 정보

| 화면 ID | 화면 | 우선 정보 | 검토할 상호작용 | 미확정 부분 |
| --- | --- | --- | --- | --- |
| UX01 | 게임 메인 | 프로젝트와 역사 여정 진입 | 시작 진입, 지도 화면으로 이동 | 로그인·이어하기·세이브 슬롯·튜토리얼 |
| UX02 | 한반도 중심 지도 | 현재 시대, 한반도와 주변 지역, 지도 범례 | 지도 이동·확대, 지역 선택, 정보 열기 | 조작 방식, 정치·문화 레이어, 탐험과 게임 행동 |
| UX03 | 시대 선택·진행 | 잠정 시대 순서, 현재 시대 | 시대 항목 확인과 지도 복귀 | 자유 이동·해금·진행 조건·시간 조작 |
| UX04 | 국가·지역 정보 | 선택 대상, 시대·위치·자료 상태 | 정보 패널 열기와 닫기 | 정보 분량, 사건 연결, 나라별 색상·문양 |
| UX05 | 역사 이벤트·진행 정보 | 장소·시점과 사건의 변화 맥락 | 사건 내용 확인과 지도 복귀 | 선택지·보상·분기·실패·강제 진행 |

표의 상호작용은 후보다. 목업의 버튼 문구와 화면 이동 표시는 게임 규칙을 확정하지 않는다. 검토 페이지에서의 화면 연결은 설계 범위를 설명하며 실제 클릭 가능한 프로토타입이나 구현으로 간주하지 않는다.

## 지도 표현

현대 해안선 참고도만 사용하며 역사 영토 경계·국가명·고고학적 정착지 위치를 임의로 추가하지 않는다. 선사시대 해안선이나 당시 지형을 복원한 지도가 아니다. 축척과 상세 지형, 시점별 영토 데이터는 고증 작업 이후 설계한다.

자료가 없는 대상은 빈 상태에서 “시대별 자료 검토 중”으로 표시한다. 검토하지 않은 영토 도형을 임시 데이터로 채우지 않는다.

## 상태와 정보의 일관성

지역을 선택하면 같은 시대와 같은 선택 대상을 유지한 채 UX04 정보를 확인하는 방식을 우선 검토한다. 시대를 바꿀 때 선택 대상이 새 시점에 존재하는지 다시 확인하고, 없으면 선택을 해제하는 방식이 후보이다. 실제 역사 데이터가 없을 때 이전 시대의 경계를 그대로 표시하지 않는다.

로딩, 빈 자료, 불확실한 자료, 오류, 선택 해제 상태가 필요하다. 역사적 사실·해석·게임 창작의 표시는 색상뿐 아니라 텍스트와 범례도 함께 제공한다. 작은 텍스트로만 구분하지 않도록 검토한다.

## 화면 전환 검토

UX01에서 UX02로 진입한다. UX02에서 UX03·UX04·UX05의 정보를 확인하고 지도로 돌아오는 구조를 검토한다. 국가·자원 운영, 계승, 전투 또는 역사 분기는 이번 와이어프레임에 확정 기능으로 추가하지 않는다.

## 디자인과 구현

기존 RoxHistory의 Noto Sans KR, 색상·간격 변수, Rox/Action 컴포넌트를 재사용한다. 최종 아트와 지도 렌더링 방식은 미확정이다. 컴포넌트와 화면은 개발 설계 문서의 후보 구성과 대응시킨다.
