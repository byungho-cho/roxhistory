# 디자인 작업 연결

Figma 파일: https://www.figma.com/design/zkbflw9fCdAlWbphhw5pSS

기존 페이지는 게임 콘셉트, 선사시대 플레이, 시대 전환과 계승, UI 구성요소로 구성한 구조 초안이다. 현재 시놉시스에 맞춘 최신 디자인은 아직 반영하지 않았다.

## 다음 Figma 범위

1. 한반도와 북방 확장 지역을 담는 전체 지도
2. 세 가지 지역 시작 경로 선택
3. 지도에서 지역으로 확대되는 화면 흐름
4. 사냥과 전리품, 업그레이드와 건설이 먼저 보이는 플레이 화면
5. 지역별 이야기가 공통 사건으로 합류하는 흐름
6. 시대 전환과 계승 및 새 인물 선택

지도는 후속 고증 후 시기별 지형과 영역을 반영한다. 검토 중에는 실제 경계로 오인할 수 있는 임의의 국경선을 만들지 않는다.
