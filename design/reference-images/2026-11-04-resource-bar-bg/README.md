# RoxHistory 상단 자원바 반투명 배경

확정 원화의 상단 자원 카운터를 위한 **배경 전용 PNG**입니다. 짙은 청록색 딤 패널과 얇은 금빛 테두리만 담았습니다. 수치, 자원 아이콘, `+`, 문자, 샘플 데이터는 이미지에 없습니다.

## 기준 및 범위

- 시각 기준: `RoxHistory_03_Always_Visible_Gather_Active_Full.png` 및 [확정 원화 Figma](https://www.figma.com/design/zkbflw9fCdAlWbphhw5pSS?node-id=689-330).
- 원화를 참고해 새로 제작한 범용 슬롯 스킨입니다. 원화에서 숫자 주변 픽셀을 잘라낸 이미지가 아니며, 픽셀 단위 동일 복제본으로 간주하지 않습니다.
- PNG 한 장을 자원 종류별로 반복 사용하고 아이콘·숫자는 현재 동적 UI로 위에 그립니다. 슬롯 폭, 수치 자리수, 자원 종류를 고정하지 않습니다.
- 이 묶음은 공유용 에셋만 추가합니다. `main`, 게임 코드, 실행 에셋, Figma 원화는 수정하지 않습니다.

## 파일

| 파일 | 캔버스 | 용도 |
| --- | --- | --- |
| `resource-slot-bg.png` | 256 × 56 px | 1x 경량본 |
| `resource-slot-bg@2x.png` | 512 × 112 px | 2x 권장본 |
| `resource-slot-bg@4x.png` | 1024 × 224 px | 4x 고해상도본 |
| `resource-slot-bg.json` | JSON | 치수, 9-slice, 알파 검사, SHA-256 |

세 PNG는 같은 아트의 해상도별 파일입니다. 색 공간은 sRGB, 형식은 8-bit RGBA PNG입니다. 외부는 실제 투명 픽셀이며 체크무늬나 배경색을 굽지 않았습니다.

## 투명도와 표시

- 모든 해상도 중앙의 알파: **192/255 = 약 75.3% 불투명**. 뒤의 지형·색이 약 24.7% 비칩니다.
- 외곽 여백 알파: **0**. 가장자리에는 안티앨리어싱에 필요한 중간 알파가 있습니다.
- 아트 생성 후 실제 반투명 사용을 위한 알파 정규화, 투명 여백 정리, 해상도별 내보내기를 수행했습니다. PNG 자체에 투명도가 들어 있으므로 일반 상태에서 이미지 틴트는 흰색, 렌더러 알파는 1로 두세요. 다시 0.75를 적용하면 지나치게 흐려집니다.
- 일반 alpha-over 블렌딩으로 표시합니다. 배경 블러 효과가 들어 있는 파일은 아닙니다.
- 전체 캔버스에는 1x 기준 약 4~5px의 안전 여백이 포함됩니다. 레이아웃 정렬은 캔버스와 실제 패널 외곽의 차이를 고려하세요.

## 재사용 및 9-slice

수평으로 긴 사각형 전체를 단순 확대하면 둥근 끝과 테두리가 찌그러집니다. **9-slice 또는 높이를 유지하는 3-slice**로 중앙 구간만 늘리세요.

원본 픽셀 기준 9-slice inset:

| 배율 | Left | Right | Top | Bottom |
| --- | ---: | ---: | ---: | ---: |
| 1x | 30 | 30 | 26 | 26 |
| 2x | 60 | 60 | 52 | 52 |
| 4x | 120 | 120 | 104 | 104 |

순서는 도구마다 다르므로 Left/Right/Top/Bottom 이름을 기준으로 설정하세요. Unity Sprite Editor의 Border 순서는 Left, Bottom, Right, Top이므로 1x에서 `(30, 26, 30, 26)`입니다.

- 이미지 외곽 캔버스 기준 좌표입니다. 자동 trim 후 동일한 inset을 그대로 적용하지 마세요.
- 목표 높이에 맞춰 전체 배율 `s = targetHeight / sourceHeight`를 먼저 정하고, 네 모서리는 그 배율을 유지합니다. 목표 폭에 따라 가운데만 늘리거나 줄입니다.
- 1x 기준 수평 3-slice는 좌측 30px, 중앙 196px, 우측 30px입니다. 목표 높이도 바뀌면 세 구간을 같은 배율로 먼저 스케일하세요.
- 9-slice 목적지 최소 폭은 `(Left + Right) * s`보다 커야 하고, 최소 높이는 `(Top + Bottom) * s`보다 커야 합니다.
- 자원 아이콘은 별도 레이어로 왼쪽 가장자리에 겹칠 수 있습니다. 숫자는 별도 텍스트 레이어로 렌더링하고, 패딩은 실제 자리수와 아이콘 크기에 맞춰 정하세요.
- UI 텍스처는 알파 보존, Bilinear 필터, Mipmap 끄기를 우선 검토하고, 플랫폼 압축 후 얇은 테두리에 변색·번짐이 생기는지 실제 빌드에서 확인하세요.

## 검증

2026-11-04 UTC 기준 다음을 확인했습니다.

- 세 파일 모두 RGBA, PNG 시그니처, 명시된 치수 일치.
- 중앙 알파 192, 완전 투명 외부 픽셀 존재, 완전 불투명 픽셀 0개.
- 글자·숫자·자원 아이콘·`+` 없음.
- 밝은 단색, 어두운 단색, 원화의 강물·지면 위에 합성하여 지형이 실제로 비치는지 육안 확인.
- 원본 비율 및 192px 폭의 3-slice 미리보기에서 둥근 모서리, 테두리 연속성, 외곽 번짐 확인.
- 원화에 맞춘 시각 에셋 검증까지 수행했으며 실제 게임 엔진의 적용·동적 수치 표시·플랫폼 빌드는 아직 검증하지 않았습니다.

제작 방식: 이미지 생성 도구로 배경 아트를 만들고 텍스트·아이콘 없는 상태로 검토한 뒤, 투명 PNG 배포를 위한 기술적 내보내기를 적용했습니다. 생성 요구: “단일 빈 캡슐, 짙은 청록색 반투명 내부, 얇고 차분한 금빛 테두리, 은은한 원화 질감, 숫자·문자·아이콘·+·장면 없음.”
