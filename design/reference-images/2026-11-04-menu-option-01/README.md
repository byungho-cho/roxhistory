## 중요한 제약
이 파일은 닫힘/열림 화면과 하단 상세 확대를 포함하는 단일 래스터 비교 원화입니다.
Figma 구조 확인 결과 아이콘, 버튼 받침, 배경, 글자 등은 독립 레이어가 아닙니다.
이 패키지는 독립 투명 PNG 에셋 추출 완료본이 아니며, 화면에 그대로 통째로 덮어 사용하는 파일도 아닙니다.
작동용 요소는 별도 투명 이미지로 재구성해야 합니다. 재구성본은 원본 추출본이라고 표기하지 말고 원화 대조 검증을 거쳐야 합니다.

## 상세 참고 영역
좌표는 위 원본 PNG의 좌상단 기준이며, 제목과 배경을 포함한 참고 범위입니다.
- 닫힘 상세: x=19, y=729, width=573, height=252
- 열림 상세: x=634, y=729, width=884, height=252
- 닫힘 게임 화면: x=20, y=182, width=731, height=442
- 열림 게임 화면: x=768, y=182, width=750, height=442

## 구현 목표
- 닫힘: 현재 상황의 대표 행동 1개 + 원형 메뉴 열기 버튼.
- 열림: 사냥, 채집, 제작, 건설, 임무, 가방과 원형 접기 버튼.
- 둥근 반투명 받침, 갈색 이름표, 밝은 테두리와 그림자를 원화 기준으로 맞춥니다.
- 활성 강조는 전체 버튼을 고정된 발광 이미지로 대체하지 말고 별도 레이어로 관리합니다.
- 아이콘·이름표·받침·열기/접기 버튼·활성 강조를 분리해 화면 크기에 맞춰 함께 배치합니다.
- 클릭 영역, 활성/비활성, 입력 처리, 펼침/접힘 애니메이션은 코드에서 처리합니다.
- 사용자 요청에 따라 대표님이 개발 담당에게 직접 전달합니다. 이 자료 등록은 코드 적용이나 개발 전달을 의미하지 않습니다.

## 검증
같은 화면 크기에서 원화와 게임을 나란히 비교하고 아이콘/받침 크기, 간격, 글자, 투명도, 상태 강조를 확인합니다.
원화에 없는 동작 또는 상태는 별도 결정합니다. 원본과 기존 게임 에셋은 보존합니다.
