- 전용 브랜치: `share/reference-assets`
- 공통 디렉터리: `design/reference-images/`
- `main`에 병합하지 않습니다. 실행 코드와 배포 에셋을 직접 변경하지 않습니다.
- 새 공유 묶음은 날짜와 목적이 드러나는 하위 디렉터리에 추가합니다.
- 정리 시점이 정해지면 지정된 묶음 또는 전용 브랜치를 함께 정리합니다. 지금은 삭제하지 않습니다.
