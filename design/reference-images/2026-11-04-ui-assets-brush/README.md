## 적용 지침

1. 승인된 작업 브랜치에서 필요한 파일만 게임 에셋 경로로 복사하고 하나의 공유 UI 컴포넌트로 참조합니다. 공유 브랜치 전체를 main에 병합하거나 참고 이미지 전체를 게임에 넣지 않습니다.
2. 같은 자원바를 자원 종류별로 재사용합니다. 아이콘·숫자·자원 증가 애니메이션·`+`·버튼 행동·접근성 이름은 기존 코드와 데이터에서 그립니다. 없는 자원/기능이나 비활성 아이콘을 새로 노출하지 않습니다.
3. 이미지 자체의 모양과 터치 영역은 분리합니다. 장식 레이어는 입력을 가로채지 않도록 설정하고 기존 버튼의 접근 가능한 터치 영역을 유지합니다.
4. 기본 tint는 흰색, 렌더러 alpha는 1입니다. 붓터치 중앙 alpha는 **192/255 ≈75.3%**가 파일에 포함되어 있습니다. Figma나 코드에서 또 0.75를 곱하지 않습니다. 전체 아이콘/문자까지 함께 흐리게 만들지 않습니다.
5. 기존 실시간 자원, 퀘스트, 진행률, 미니맵, 프로필, 메뉴 펼침/접힘 상태를 그림으로 대체하지 않습니다. 미니맵 링의 빈 내부에는 실제 지도 렌더링을 놓습니다. `N`, 방향 표시, 플레이어 위치는 동적으로 분리합니다.
6. 진행바 필의 111px은 내보내기 캔버스 길이이지 고정 진행률이 아닙니다. 실제 목표 길이로 가로 슬라이스 후 현재 상태 비율로 clip합니다. 0%는 완전히 빈 상태로, 100%는 넘침 없이 표시합니다.
7. 프로필은 현 main과 같은 실루엣을 내보낸 것입니다. 원본 PNG에 있던 금색 원을 되살리거나 얼굴을 새로 생성하지 않습니다.
8. 기존 메뉴·펼침 파일에는 글리프가 포함돼 있습니다. 별도 글리프를 중복 올리지 않습니다. 닫기 동작에는 기존 `collapse.svg`를 계속 쓸 수 있으며 새 기능을 뜻하지 않습니다.

## 슬라이스 및 상태

- **붓터치: 수평 3-slice 권장.** 1x left=32, right=88 / 2x left=64, right=176. 왼쪽 둥근 끝과 오른쪽 붓결을 고정하고 가운데만 늘립니다. 목표 높이 H에서 먼저 전체 배율 H/56을 적용하고 목표 폭은 `120×H/56`보다 커야 합니다. 높이 방향 9-slice는 붓결을 찌그러뜨리므로 사용하지 않습니다. 캔버스 자동 trim 금지.
- **퀘스트 패널: 9-slice 후보.** 1x L/R/T/B=20/20/20/20, 2x=40/40/40/40. 둥근 모서리·그림자 밖으로 슬라이스하지 않도록 엔진에서 확인합니다.
- **진행바: 수평 3-slice.** 트랙 L/R=7/7, 필 L/R=5/5 (1x). 2x는 두 배입니다. 세로는 일정하게 유지합니다.
- **돌 받침·원형 받침·미니맵 링·아이콘·조이스틱:** 9-slice 없음. 비율 유지. 돌 질감이나 원을 가로로 늘리지 않습니다.
- Normal/Pressed/Selected/Disabled/Focus를 각각 새 PNG로 만들지 않았습니다. 같은 그림에 코드의 눌림 효과, 별도 강조 테두리/광, 비활성 tint, 포커스 표시를 사용합니다. Selected 광은 아이콘 뒤에 두고 숫자·글자가 함께 흐려지지 않게 합니다.

## 품질 검사와 개발 완료 조건

이 묶음에서는 PNG 디코딩, 1x/2x 치수, 실제 알파, SHA-256, 투명 외곽·밝은/어두운 배경, 붓터치 84×27·96×36·192×56·256×56·360×56의 3-slice, 전체 시각 미리보기를 확인했습니다. 원본은 별도 보존했습니다.

아래 항목은 **개발 담당이 적용 후 검증할 항목**이며 아직 통과했다고 기록하지 않습니다.

- 기존 정적 HUD 사각형과 새 배경이 겹쳐 이중으로 보이지 않는지, 알파가 두 번 곱해지지 않는지.
- 실제 화면의 밝은 지형·강물·어두운 부분에서 숫자 가독성, 아이콘 경계, 압축 후 halo/번짐.
- 최대 수치·긴 문구·작은 해상도·안전영역에서 숫자와 붓결 끝이 겹치지 않는지.
- 자원 증가, 선택/해제, 진행 0/중간/100%, 메뉴 열기/닫기, 반복 터치, 뒤로가기에서 상태·입력이 유지되는지.
- 장식 레이어가 터치를 가로채지 않고 조이스틱·메뉴·버튼 타깃이 기존대로 동작하는지.
- PNG import 시 알파 보존, UI 필터/압축 설정 및 대상 Android 기기 실제 화면 확인.
- 적용 전후 스크린샷, 실행한 검사/미실행 검사, 소스 커밋과 개발 PR을 전달할 것. 배포·main 병합은 별도 절차.

## 출처와 사용 권한

외부 게임 화면·마켓 에셋·새 폰트는 이 묶음에 넣지 않았습니다. 기존 프로젝트 이미지/네이티브 Figma 레이어는 manifest의 고정 Git 커밋 또는 노드 링크로 추적합니다. 기존 파일에 새 라이선스를 부여하지 않으며, 원자료의 권리·조건은 기존 프로젝트 기록을 따릅니다. 이 작업에서 원자료 전체의 권리를 별도로 감사한 것은 아닙니다.

선택 붓터치와 새 돌 받침은 프로젝트 요청에 따라 이미지 생성 도구로 만든 원본입니다. 이번 작업의 새 이미지 생성은 돌 받침 **1회**뿐입니다. 정확 추출본으로 표시하지 않습니다. 공개 저장소 공유가 요청된 개발용 파일만 넣고 대화 원문·개인 파일·인증정보는 넣지 않았습니다.

`source/` 고해상도 원본은 재내보내기용이며 게임 로딩에 직접 쓰지 않습니다. 새 돌 받침의 생성 지시 요지는 아래와 같습니다.

> 확정 원화 하단 버튼의 따뜻한 올리브·갈색 사암 받침 한 개만, 아래 어두운 이름판은 빈 상태. 아이콘·한글·숫자·선택 광·배경 장면 없이 실제 투명 알파. 원화풍을 유지하고 새로운 기능 기호를 만들지 않음.
