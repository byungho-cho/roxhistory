## 개발 적용

1. 게임 코드나 main은 이 공유 작업에서 변경하지 않았습니다. 이 PNG를 새 버전 파일로 가져오고 기존 UI·컨트롤러·아이콘은 재사용합니다.
2. 건물·주민·동물·나무·바위·채집물·격자·직선형 길·정사각/직사각 건물 점유 영역은 게임 오브젝트 또는 별도 레이어로 배치합니다. PNG에 다시 굽지 않습니다.
3. 원화의 시각적 방향에 맞게 좌표 변환과 화면 투영을 설정합니다. 6×6/4×4는 논의된 점유 예시이며 이 파일이 타일 크기나 좌표를 확정하지 않습니다.
4. 강변, 이동 가능 영역, 충돌체, 가림 순서, 건설 후보지와 기존 저장 위치를 **새 배경 기준으로 재매핑**해야 합니다. 이전 terrain의 경계 좌표를 그대로 재사용하지 않습니다.
5. 외곽 장식과 구름 아래를 무조건 이동/건설 가능으로 취급하지 않습니다. 카메라 축소·이동 경계를 검증합니다. 현재 구름은 PNG에 합쳐져 있어 개별 애니메이션이 필요하면 별도 분리가 필요합니다.
6. 완전한 반복 타일(seamless)로 설계하거나 경계 연결 검증하지 않았습니다. 무한 확장 월드맵에 그대로 반복 사용하지 않습니다.
