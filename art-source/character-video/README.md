# 캐릭터 영상 원본 보관

이 디렉터리는 Godot 프로젝트 `game/` 밖에 둡니다. 원본은 이곳에, 실제 게임에서 재생하는 변환본은 해당 기능의 `game/assets/` 경로에 둡니다. 여기 추가한 파일은 APK/PCK에 자동으로 포함되지 않습니다. 아직 등장하지 않은 캐릭터의 원본도 준비되는 대로 이곳에 보관하고, 승인된 화면에서만 연결합니다.

캐릭터별 폴더에는 승인 영상, 용도, 원본 SHA-256, 인코딩 및 실제 사용 경로를 기록합니다. 임시 생성본과 미리보기, 동일한 배포본 복사본은 함께 보관하지 않습니다.
