Eight original PNGs from the overlap-v004 handoff. All button hashes are unchanged from that handoff (and from v003). Each includes its circle, icon, brush label and Korean text. Use the full canvas, without alpha trimming or a duplicate label.

- Move, upgrade and demolish: 288×288 source, 96×96 baseline display.
- Close: 144×144 source, 48×48 baseline display.
- Disabled PNGs already contain 35% alpha (maximum 89/255). Keep node modulation opacity at 1.0 to avoid double dimming.
- The 44-source-pixel upward label shift is in the artwork.
