텍스처 최대 1024, 높이 2 모델 단위, 원점은 지면. 거칠기 0.93·반사 0.12·노멀 강도 0.18, 주인공과 같은 따뜻한 조명을 사용한다. 소스 해시와 변환 수치는 provenance.json에 기록했다. 편집 가능한 원본은 GLB이며 변환 절차는 Blender 4.5용 Python으로 재현할 수 있다.

원본 3종 모두 뼈대·동작 0개. 현재는 실제 3D의 제자리 호흡만 적용한다. 보행·달리기·먹이 활동에는 별도 리깅이 필요하다. 사냥·전투·드롭 기능은 추가하지 않았다. 최대 4개체, 화면 밖 렌더 중지, 화면 안 20Hz 갱신, 확대 시 512px 렌더링을 사용한다.

사용 조건: 사용자 제공 Meshy 자산. 계정별 이용 조건은 기존 원본의 provenance를 따른다. 새 외부 모델은 추가하지 않았다.
