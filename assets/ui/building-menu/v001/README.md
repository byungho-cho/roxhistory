# RoxHistory 건물 원형 메뉴 에셋 v1

승인된 시안 기반의 개별 투명 PNG 5종입니다. 공통 원형 바탕과 아이콘은 별도 레이어로 합성합니다. 텍스트는 이미지에 없으며 게임의 별도 Label로 표시합니다.

- 이동: icon-move.png
- 업그레이드: icon-upgrade.png
- 철거: icon-demolish.png
- 닫기: icon-close.png
- 공통 바탕: button-base.png

모두 1254x1254 RGBA입니다. 그림이 차지하는 알파 영역이 서로 다르므로 동일 파일 크기만으로 아이콘을 맞추지 마세요. manifest의 visible_bounds를 기준으로 중앙 정렬하고 아이콘 가시 영역은 원형 버튼 지름의 약 65~70%로 표시하세요. 업그레이드는 주요 버튼, 닫기는 작은 버튼으로 표현합니다.

권장: 버튼과 텍스트는 화면 UI 좌표에 두고 건물의 월드 위치를 투영해 따라갑니다. 글자는 이동/업그레이드/철거를 별도 표시합니다. 버튼 입력 영역은 시각 크기와 독립적으로 확보합니다.

정적 PNG, 프레임 애니메이션 없음. 실제 게임 크기와 터치 동작은 적용 후 검증해야 합니다. 원본 PNG는 변경 없이 보존했으며, 새 에셋은 생성 도구로 승인 시안에서 분리 재현한 것으로 원시 벡터 추출은 아닙니다.
