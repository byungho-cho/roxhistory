# RoxHistory 메뉴 통합 PNG v002

2026-11-06. 원형 버튼, 아이콘, 검정 붓터치 레이블, 한글 메뉴명을 한 장에 합친 투명 PNG입니다. 원본 그림을 다시 생성하거나 덮어쓰지 않고 Figma의 기존 이미지와 컴포넌트를 재사용했습니다.

## 전달 파일
- exports/: 업그레이드·철거 정상/비활성, 업그레이드 금색 강조, 닫기 정상/비활성, 사이드 움집·초소 정상/비활성. 총 11종.
- hold/: 이동 정상/비활성 2종. 기존 승인 시안의 ‘이동’을 유지한 참고 파일이며 실제 기능·최종 문구 결정 전에는 운영 연결하지 않습니다.
- sources/: 기존 원형 메뉴 원본과 개별 이미지의 수정 없는 복사본.
- qa/: Figma 합성 결과 확인 이미지. 실제 게임 화면 검증을 대신하지 않습니다.
- manifest.json: 크기, 중심점, 레이블 영역, 원본 연결, SHA-256.

## 적용 규격
- 건물 액션 288×288 RGBA, 표시 96×96. 원형 중심 (144,108), 반지름 96. 공통 중심 pivot (0.5,0.5).
- 닫기 144×144 RGBA, 표시 48×48. 원형 중심 (72,72), 지름 108. 터치 영역은 별도로 최소 44×44.
- 사이드 움집·초소 216×240 RGBA, 표시 72×80. 아이콘 슬롯 하단 y180, 같은 텍스트 기준선.
- 정상/비활성/강조의 캔버스와 기준점은 동일합니다. PNG를 알파 경계로 자동 trim하지 마세요.
- 한글은 이미지에 포함됩니다. 게임에서 추가 Label을 겹치지 마세요.
- 비활성 PNG는 35% 불투명도를 이미 포함합니다. 같은 비활성 알파를 한 번 더 곱하지 마세요. 기능 비활성 판정과 클릭 차단은 게임 로직에서 별도로 처리합니다.
- 업그레이드 강조는 원본 바탕·아이콘에 금색 발광을 추가한 상태입니다. 원본 시안의 강조 의도를 따르지만 원화에서 픽셀 단위로 추출한 효과는 아닙니다.

## 배치
선택 건물 하단의 아래로 열린 U자 배치. 가운데 업그레이드가 양옆보다 아래에 옵니다. 닫기는 건물 오른쪽 별도 위치입니다. 화면 하단 공간 부족으로 전체 메뉴를 건물 위로 뒤집지 마세요. 사이드 메뉴는 건설 버튼 바로 위 가로 배치, 움집 중심과 건설 중심 정렬을 유지합니다. 이동은 활성화하지 않습니다.

## 검증 범위
Figma 원본과 합성 결과를 육안 대조했고, 13개 PNG의 픽셀 크기·RGBA·투명 배경·상태별 동일 캔버스·해시를 확인했습니다. 원본은 보존했습니다. 실제 게임의 세로/가로 화면, 최소/최대 줌, 터치/반복 클릭, HUD 간섭, 비활성 클릭 차단 및 APK는 아직 검증하지 않았습니다. 이동 기능·최종 운영 문구는 미결입니다.
