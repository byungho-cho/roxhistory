# 지도 참고 데이터

- 출처: Natural Earth 1:50m physical land
- 원본: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_land.geojson
- 이용 조건: https://www.naturalearthdata.com/about/terms-of-use/
- 확인일: 2026-10-28
- 가공: 동경 120~135도, 북위 32~44도 범위로 잘라 Mercator 방식으로 동일 축척 투영한 SVG.
- 포함: 현대 육지와 해안선의 단순화된 참고 형태.
- 제외: 국가 경계, 역사 영토, 선사시대 지형 복원, 유적 위치, 역사적 세력권.

이 지도는 와이어프레임의 화면 구성을 살피기 위한 참고도다. 고증 지도나 실제 게임 지도 데이터로 사용하지 않는다. 고정 화면용 범위를 최종 지리적 게임 범위로 확정하지 않는다.
