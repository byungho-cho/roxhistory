## 내일 반영할 범위

### 1. BGM 연결

A303에서 채택 BGM을 자연스럽게 반복 재생합니다. 지역을 바꾸거나 확대할 때마다 음악을 다시 시작하지 않습니다. 화면 진입·이탈은 부드럽게 연결하고 기존 소리 설정과 앱 백그라운드 처리를 존중합니다. 백업 음원은 자동 재생 목록에 넣지 않습니다.

### 2. 선택했을 때의 소리 교정

현재 게임의 `DemoSoundscape.cue("ui")` 경로와 지역 선택 동작을 확인한 뒤, 선택음이 전자 비프처럼 튀지 않도록 짧고 부드러운 소리로 교체·조정합니다. 현재 보관한 `sfx.ui.soft_tap.v001`은 비교 가능한 교정 후보이며 별도 청음 승인은 아직 없습니다.

일반 버튼과 지역 선택의 소리가 필요하면 강도만 구분합니다. 짧게 연속 선택해도 소리가 중복되거나 과도하게 겹치지 않도록 확인합니다. 기존 효과음과 새 효과음이 동시에 울리지 않게 실제 연결 위치를 확인합니다.

### 3. 선택 이펙트 보완

선택한 위치와 유물이 더 명확히 느껴지도록 짧은 강조·부드러운 전환·절제된 빛 또는 입자 효과를 보완합니다. 원래의 **선택 110% / 미선택 90%** 크기 기준과 지도 실제 위치 안내를 유지하며, 위치 원을 다시 크게 키우지 않습니다.

정보 패널·유물·그림자·장식의 전환이 함께 읽히도록 합니다. 최근 수정한 패널 잔상·겹침 문제가 다시 생기지 않게 지역을 빠르게 바꾸는 상황도 확인합니다. 강조 효과가 제목·선택 버튼·지명의 가독성을 가리지 않게 합니다.

### 4. 새·물고기 연출과 잔잔한 환경음

- 기존 새·물고기 연출을 자연스럽게 다듬습니다. 지도 장식 연출 범위이며 새 주민·동물 게임 시스템 개발을 뜻하지 않습니다.
- 새는 지나치게 많거나 빠르게 반복되지 않게 하고, 물고기는 가끔 보이는 움직임과 작은 수면 효과 정도로 유지합니다.
- 소리는 **새소리와 바람 또는 물소리**로 공간감을 더하되 **BGM이 중심**이 되게 합니다. 물고기에 지속적인 별도 소리를 붙일 필요는 없습니다.
- 바람·물소리는 한 종류를 중심으로 낮고 잔잔하게 사용합니다. 여러 환경음을 계속 쌓아 소음처럼 만들지 않습니다. 새소리는 드물고 낮게, 날카로운 고음이나 규칙적인 반복을 피하는 방향입니다.
- 기존 물소리 원본과 사용 조건은 [audio-sources](../audio-sources/README.md)를 유지합니다. 최신 개발본에서 사용 중인 실제 물 녹음과 사용자가 수용한 낮은 음량을 먼저 기준으로 확인합니다. 소리가 거칠거나 BGM을 가리면 환경음을 더 낮춥니다.

## 확인할 결과

1. A303 진입·지역 선택·확대·복귀에서 BGM이 불필요하게 재시작하거나 겹치지 않음.
2. 선택음이 짧고 자연스럽고, 연속 입력에도 과하게 커지거나 두 번 나지 않음.
3. 선택 위치와 전환이 명확하며, 패널 잔상과 글자 가림이 없음.
4. 새·물고기 연출과 환경음은 잔잔하고 BGM을 방해하지 않음.
5. 소리 끄기·앱 전환 등 기존 동작을 유지함.
6. 실제 출력으로 BGM·선택음·환경음을 함께 들어보고 판단함. 코드 검사나 녹음 파형 확인만으로 청취 승인을 대신하지 않음.

반영 후 짧은 실행 화면·소리 비교와 확인 범위를 남깁니다. 추가로 결정되는 음악·효과음도 실제 파일, 버전, 출처, 상태, 결정 이력을 같은 Git 변경에 보관합니다.
