# RoxHistory 음악·효과음 기준

결정일: **2026-11-01**. A303 지역 선택 BGM은 **1안 ‘별빛의 환상’ 채택**, 2안 ‘햇살의 모험’은 **백업 보관**입니다. 현재 통통 튀는 버전의 멜로디와 112 BPM을 기준으로 합니다.

| 구분 | 파일 | 상태·용도 |
| --- | --- | --- |
| BGM 기본 | [별빛의 환상 v001](bgm/approved/a303_starlight/v001/loop.wav) | 채택본. 몽환적이고 환상적인 A303 지역 선택 분위기 |
| BGM 백업 | [햇살의 모험 v001](bgm/backup/a303_sunlight/v001/loop.wav) | 보존용. 경쾌하고 상쾌한 대안, 기본 재생 대상 아님 |
| UI 효과음 | [터치음 교정 후보 v001](sfx/review/ui_soft_tap/v001/tap.wav) | 제작·로컬 구형 데모 확인 완료, 별도 청음 승인 대기 |

정확한 파일 ID, 경로, 상태, 길이, 음량, 해시, 반복 지점은 **[catalog.json](catalog.json)**을 기준으로 확인합니다. 두 BGM의 평균 음량을 맞춰 비교할 수 있게 했습니다.

## 개발 반영 일정과 범위

사용자 지시로 **실제 게임 반영은 2026-11-02에 이어갑니다**. 오늘은 음원과 결정을 보관합니다. **[내일 개발 인수인계](handoff-2026-11-02.md)**에 BGM·선택음·선택 이펙트·새와 물고기·잔잔한 환경음의 범위를 정리했습니다.

## 개발 담당 적용 안내

- A303의 기본 음악은 `bgm.a303.starlight.v001`입니다. 백업을 무작위로 섞거나 자동 대체하지 않습니다.
- 두 BGM 모두 **44,100 Hz / 스테레오 / 16-bit PCM WAV**, **112 BPM / 24마디 / 51.428571초**입니다. 게임용 반복 구간만 담았으며 청음용 영상 같은 마무리·페이드아웃이 없습니다.
- 반복 구간은 **0번 샘플부터 2,268,000번 샘플 직전까지**입니다. WAV 자체에 별도 반복 지시 메타데이터가 들어 있지 않으므로 재생기·Godot 임포트 설정에서 정방향 반복을 활성화합니다. 출력 재생에서는 반복 경계의 끊김도 확인합니다.
- Godot에 도입할 때 채택본만 `game/assets/audio/`에 복사하고, 카탈로그 ID와 원본 SHA-256을 런타임 음원 메타데이터에 남깁니다. 압축·리샘플링한 배포 파일을 만들면 원본은 보존하고 변환 조건과 새 해시를 기록합니다.
- 지역 선택·확대 상태를 바꿀 때마다 처음부터 다시 재생하지 않고 기존 BGM 재생을 유지하는 방향입니다. 화면 진입·이탈, 앱의 백그라운드 전환, 기존 소리 설정을 함께 처리합니다. 최종 믹스 음량은 UI·환경음과 실제 출력에서 확인해야 합니다.
- 이번 변경은 **오디오 원본·선택 결정·인수인계 자료 저장**입니다. 최신 개발본의 BGM 재생 연결이나 APK 배포 완료를 뜻하지 않습니다.

### 터치음의 확인 범위

보관한 `tap.wav`는 이 대화에서 만든 부드러운 교정 후보입니다. 구형 로컬 데모에 적용해 기존 검사와 시작을 확인했으나, 사용자가 이 파일을 따로 듣고 확정한 것은 아닙니다.

최신 `main`의 UI 소리는 `game/assets/audio/ui.wav`이며 `game/scripts/soundscape.gd`의 `DemoSoundscape.cue("ui")`로 재생됩니다. 두 파일은 다른 소리입니다. 이 후보를 최신 게임의 확정 효과음으로 오인하거나 기존 UI 소리와 이중 재생하지 않습니다. 교체 시 기존 소리와 음량을 맞춰 들어보고 사용자 확인 상태를 갱신합니다.

## 앞으로 결정되는 소리의 저장 규칙

1. 사용자에게 채택된 음악·효과음은 `bgm/approved/` 또는 `sfx/approved/`에 저장하고, 보존 지시를 받은 대안은 `backup/`에 저장합니다. 아직 확인하지 않은 후보는 `review/`로 구분합니다.
2. 파일을 바꿀 때 기존 버전을 덮어쓰지 않고 `v002`처럼 새 버전을 추가합니다. 카탈로그의 기본 ID와 상태를 함께 갱신합니다.
3. 결정일·용도·출처·확인 상태·포맷·길이·음량·해시를 기록하고, 반복 음악은 반복 구간을 명시합니다. 결정 이력은 [decisions.md](decisions.md)에 덧붙입니다.
4. 결정된 실제 음원 파일과 문서를 **같은 Git 커밋**으로 저장합니다. 개발 담당이 접근할 수 있도록 브랜치를 원격 저장소에 올리고 변경 링크를 남깁니다.
5. 기존 환경음·외부 음원은 [audio-sources](../audio-sources/README.md)의 출처·이용 조건을 유지합니다. 이 폴더의 창작 음원에는 외부 샘플을 사용하지 않았습니다.

현 시점의 채택은 음악 방향과 파일 선택에 대한 것입니다. 최신 게임에 적용한 뒤의 출력 음량·반복 재생·실기기 청취 검증과 구분합니다.
