# RoxHistory 음악·효과음 기준

## 2026-11-04 타이틀–터전 선택 연속 재생

참고 이미지 11(터전 선택), 12(타이틀)에 따라 타이틀에도 기존 A303 채택곡 **별빛의 환상**을 연결했다. 두 화면이 같은 플레이어를 사용하여 전환 때 재시작하지 않는다. 플레이의 첫 불씨는 유지한다. 새 음원 파일/유료 생성은 없으며 기존 -10dB, 음소거·중단/복귀 정책을 유지한다. 실제 반복 전환은 자동 믹서 검사, 직접 청취 승인은 별도다.

## 2026-11-03 플레이 음악 추가

플레이 화면에 [첫 불씨 · 경쾌 1안](bgm/approved/first_embers_lightly_bright/v001/README.md)을 연결합니다. A303의 별빛의 환상은 유지합니다. 현재 확보한 파일은 MP3와 MIDI이며 WAV 마스터는 미수령입니다. `play_bgm.wav`는 MP3를 PCM16으로 디코딩한 **손실 원본의 런타임 파생본**입니다. 무손실 마스터가 아닙니다. 48kHz 스테레오, 3,544,615프레임, 반복 경계 가드 적용, 플레이 게인 -12dB입니다. 출처 커밋은 `518001ce`입니다.

`scripts/register_play_music.py`가 해시·프레임을 확인하고 메타데이터를 기록합니다. `game/tests/play_music_tests.gd`는 실제 믹서의 반복 경계, 지도 전환, 음소거·중단·복귀, 팝업 감쇠를 검사합니다. 자동 검사는 청취 승인을 뜻하지 않습니다.

나무·돌 타격음은 [v002](sfx/implemented/gather_contact/v002/README.md)의 짧은 원본 합성음으로 연결합니다. 이전 파일은 `sfx/archived/gather_contact/v001/`에 보존합니다. 직접 청취 및 실물 기기 음량 균형은 미검증입니다.

**A303 기본 BGM은 1안 ‘별빛의 환상’**입니다. 2안 ‘햇살의 모험’은 백업으로 보관합니다. 사용자 결정일은 2026-11-01이며, 2026-11-02 개선본 `v0.1.16-a303-audio`에 채택곡과 선택음·잔잔한 환경음을 연결했습니다.

## 게임 적용 기준

- 음악은 **112 BPM / 24마디 / 51.428571초**, **44.1kHz 스테레오 PCM16**입니다. 페이드아웃이 없는 반복용 원본이며 추가 손실 압축을 사용하지 않습니다. 반복은 **0번 샘플부터 2,268,000번 샘플 직전까지**입니다.
- Godot 4.5의 PCM 반복 경계 읽기에 대비해 재생 리소스 메모리에 시작 프레임을 한 번 덧붙입니다. 원본 파일과 2,268,000프레임 반복 길이는 바꾸지 않습니다. [원인과 검증](../../docs/shared-reports/2026-11-02-a303-audio/report.md)을 참고하고 이 가드를 제거하거나 반복 끝을 늘리지 않습니다.
- `game/scripts/soundscape.gd`가 음악·효과음·환경음을 관리합니다. A303 지역·배율·화면 크기를 바꿔도 음악을 다시 시작하지 않습니다. 앱 백그라운드·음소거에서는 위치를 보존해 멈추고, A303을 나갈 때는 부드럽게 종료합니다.
- 음악은 -10dB, A303의 물소리는 -25dB 재생 게인을 사용합니다. 물소리는 기존 실제 물 녹음을 재사용하며 A303에서는 바람을 함께 재생하지 않습니다. 이 숫자는 재생 게인이며 사용자 청취 승인 음량을 뜻하지 않습니다.
- 새소리는 첫 9~14초 후, 이후 22~36초의 불규칙한 간격으로 -20dB 게인에서 재생합니다. 팝업·앱 비활성화 중에는 새 호출을 보류합니다. 물고기에 별도 소리를 붙이지 않습니다.
- 일반 UI와 지역 선택은 서로 다른 짧은 소리를 사용합니다. UI·선택 간 공통75ms 제한을 사용합니다. v0.1.17부터 새 인터페이스 소리가 재생될 때 이전 UI/선택음 꼬리를 멈춰 동시에 하나만 재생하며, 다른 효과음용 재생 슬롯은 유지합니다.
- 배포 원본과 변환 기록은 `game/assets/audio/manifest.json`에 있습니다. 채택곡의 런타임 WAV는 원본 SHA-256과 동일합니다. 기존 환경음의 [출처·이용 조건](../audio-sources/README.md)을 유지합니다.

## 재현·확인

- `python scripts/build_a303_audio.py`: 채택곡 복사 및 새 UI·선택·새소리 파일과 메타데이터 재현. Python과 NumPy를 사용합니다. 원본 버전이 달라지면 기존 파일을 덮어쓰지 않고 실패하므로 새 버전을 만들어야 합니다.
- `python scripts/build_demo_audio.py`: 기존 효과음·환경음과 이번 음원을 함께 재현합니다.
- `python scripts/verify_demo_audio.py`: 런타임 파일과 원본의 해시·포맷·음량·반복 경계를 검증합니다.
- `game/tests/a303_audio_tests.gd`: 음악 유지·실제 반복·연타·음소거·앱 전환 검증입니다. [이번 실행 결과와 미리보기](../../docs/shared-reports/2026-11-02-a303-audio/report.md)를 함께 확인합니다.

## 앞으로 결정되는 소리의 저장 규칙

1. 채택 음악·효과음은 `approved`, 보존 대안은 `backup`, 청음 대기는 `review`, 게임 연결 후 사용자 출력 확인 전은 `implemented`로 구분합니다.
2. 수정은 새 버전으로 추가하고 기존 원본을 보존합니다. 기본 ID와 상태를 카탈로그에 기록합니다.
3. 결정일·용도·출처·확인 상태·포맷·길이·음량·해시·반복 구간을 남기고 [decisions.md](decisions.md)에 이력을 추가합니다.
4. 실제 음원과 문서를 같은 Git 변경으로 보관하고 원격 변경 링크를 남깁니다. 재생 연결·자동 검증·실기기 청취 승인을 구분해 보고합니다.

향후 팀장과 개발 담당의 역할은 [역할 분담 문서](../../docs/team-workflow.md)를 따릅니다. [11월 1일 인수인계 원문](handoff-2026-11-02.md)은 당시 결정 이력으로 보존합니다.
