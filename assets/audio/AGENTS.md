# 오디오 작업 지침

사용자는 앞으로 제작해 결정한 음악·효과음도 개발 담당이 참고하도록 Git에 따로 저장하라고 요청했습니다.

- 이 폴더의 README와 catalog.json을 먼저 확인합니다. 파일 선택·상태는 카탈로그를 기준으로 합니다.
- 채택본·백업·확인 대기 후보를 구분하고, 사용자의 결정 없이 백업을 기본 재생 대상으로 승격하지 않습니다.
- 새로 결정되거나 수정된 음원은 버전 디렉터리에 실제 파일을 보관하고, 카탈로그·결정 이력을 같은 커밋으로 갱신합니다. 기존 원본 버전은 보존합니다.
- 원격 Git 저장 여부와 게임 내 적용·출력 검증 여부를 구분해 보고합니다. 새 승인 절차를 만들지 않고 기존 사용자 승인 범위에서 작업합니다.
