## 화면 및 동작
1. 기존 시작 화면의 `화면을 터치하여 시작`을 누르면 마을 진입 대신 인트로 재생을 먼저 시작한다.
2. 화면 비율을 유지하고 검정 여백으로 채운다. 영상 자르기·늘이기를 하지 않는다.
3. 스킵 문구는 최신 기준 `화면을 터치하여 스킵`. 시작 문구와 동일한 하단 중앙 위치와 글자 스타일을 사용한다. Figma 시안에도 같은 문구와 좌표를 적용한다.
4. 문구 영역을 누르면 즉시 재생을 중단하고 다음 화면으로 이동한다. 참고 구현은 문구 버튼만 클릭 가능하며 전체 화면 아무 곳 터치는 스킵하지 않는다. 전체 화면 스킵으로 바꾸려면 시안 및 동작 기준을 함께 확정한다.
5. 15초 자연 종료와 스킵은 같은 완료 함수를 사용한다. 기존 저장은 기존 마을 진입 함수, 저장 없는 첫 진입은 기존 챕터 선택으로 보낸다. 저장 생성이나 초기화 동작을 바꾸지 않는다.
6. 시작 연타, 스킵 후 종료 신호 중복, 뒤로 가기를 안전하게 처리한다. Android 뒤로 가기는 스킵과 동일하게 동작한다.
7. 백그라운드 전환 시 영상을 일시정지하고 복귀 시 이어 재생한다. 화면 크기 변경으로 영상이 처음부터 재생되지 않게 한다.
8. 파일 누락/로딩 실패 시 기존 다음 화면으로 진행하며, 디코더 이상 시 활성 재생 20초 제한으로 막힘을 방지한다.
