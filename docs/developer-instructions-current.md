## 주민 요구사항

외형 승인 주민은 성인 남성 2명·성인 여성 2명·노인남녀·어린이남녀, 총8종입니다. [원본·코드·노드](../design/assets/residents/v001/README.md)를 사용합니다. 전체 약 10종 원화 목표 중2종은 미정이며, 게임 동시 배치 인원은 정하지 않았습니다.

원시적인 털가죽·단순 끈 매듭·맨발과 개별 얼굴·머리·체형을 유지합니다. 노인/어린이 색상은 회청록·자주/적갈색·초록·황토/노랑입니다. 승인 원화8종은 정적 투명PNG입니다. 별도로 [사용자 제공 주변 인물3D 원본5개](../design/assets/residents-3d/reference-v001/README.md)를 Git LFS에 보관했습니다. 원본 GLB에는 skins·animations가 없으며 원화별 대응은 미지정입니다. 원본을 보존하고 검토·경량화·재질/접점 확인·리깅·보행을 별도 작업본에서 진행합니다. 보관을 실제 게임 적용 완료로 표시하지 않습니다.

주민의 목적은 주변 동물처럼 자연스럽게 돌아다니는 마을 생활 연출입니다. 이동→잠시 멈춤→둘러보기 등의 흐름, 연령별 크기/속도, 건물·강·자원 접근을 막지 않는 경로와 가림 순서, 앱 중단/복귀와 화면 밖 처리를 검토합니다. 정지 이미지를 미끄러뜨리는 것만으로 보행 완료를 표시하지 않습니다. 새 경제·전투·보상 시스템을 외형 승인에서 임의 확장하지 않습니다.

동물 보행 리깅, 어군 개별 꼬리/분산, 전체 접힘 HUD·구름 경계, 실물 기기·직접 청취는 미완료입니다. 주민 구현 시 기존 채집 접근·나무/돌 각 1회 지급·건설2초·보상10·스타일 저장·핀치·중단/복귀가 손상되지 않도록 확인합니다. 원본 음악·PCM 반복 구간과 기존 패키지/서명을 유지합니다.

구현 후 동일 구도 화면, 움직임 영상, 관련 로컬/CI 결과, Android 확인 범위, 남은 사항을 남깁니다. 새 APK를 만들 때는 현재 배포보다 높은 versionCode와 기존 서명을 사용하고 GitHub 다운로드 링크·소스 커밋·SHA-256을 제출합니다. 이번 문서 현행화만으로 새 APK를 만들지는 않습니다.
