## 첫 진입 흐름

1. 전체 지도에서 한반도와 주변 지역, 시작 후보 표식을 봅니다.
2. 표식이나 대응 지역 카드를 눌러 후보를 선택합니다.
3. 선택 표식과 설명 패널을 갱신합니다. 다른 후보를 누르면 교체합니다.
4. '이곳에서 시작'을 누르면 중복 입력을 막고 선택 지역 ID와 시작 조건을 저장합니다.
5. 선택 지역으로 확대하며 해당 장면을 준비합니다. 완료 뒤 기존 강변 마을형 플레이 화면으로 이어집니다.
6. 실패하면 지도 선택을 유지하고 재시도를 제공합니다. 시작 연출은 건너뛸 수 있도록 후속 설계합니다.

첫 구현은 암사동형 강변 정착 경로를 예시로 합니다. 다른 지역도 같은 강변 화면을 복제해 완성했다고 처리하지 않습니다. 플레이 시안의 레벨 3, 자원량, 퀘스트와 거점 상태는 신규 게임 값이 아니며 첫 진입 데이터는 별도 설계합니다.

## 후보지와 지도 상태

| 후보 | 비교할 첫 경험 | 검토 상태 |
| --- | --- | --- |
| 전곡리 | 사냥·제작 | 구석기 유적. 시기·시작 조건 검토 필요 |
| 암사동 | 정착·마을 | 신석기 강변 취락. 이번 진입 예시 |
| 동삼동 | 해안 생활·교류 | 신석기 패총. 지역 전용 장면 후속 검토 |

세 후보는 초기 상세안의 유형 비교를 위한 시안이며 동일 시점의 동시 마을로 확정하지 않습니다. 후보별 시작 시기, 공통 이야기 합류 방식과 지리 좌표는 고증 검토합니다. 지도에는 현대 국가 경계나 역사 영토를 임의로 넣지 않습니다.

현대 해안선 참고 SVG를 유지해 선택 동선을 표현했습니다. 지도 페이지의 단순 지형은 구성 검토용이며 최종 아트가 아닙니다. 실제 지형·식생·거점 표식은 기준 그림체의 에셋으로 제작하고 시대별 해안선은 별도 검토합니다.

## 모바일 화면 제안

가로 화면을 기본 제안으로 잡고 화면 비율이 달라도 지도·표식·패널 상태를 유지합니다. 터치 영역 최소 48dp를 목표로 하고, 근접 표식은 확대 또는 콜아웃·카드로 선택하도록 설계합니다. 노치와 시스템 영역을 피하며 뒤로가기·화면 잠금·앱 복귀와 진행 저장을 실기기에서 확인합니다. 수익화·멀티플레이·서버 구성은 이번에 확정하지 않습니다.
