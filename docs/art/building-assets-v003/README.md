## 완료 상태를 구분해서 사용하세요

**재사용 검수 통과 12개:** 움집 4개, 초소 4개, 공통 바닥 4개. 움집 L1·L2·L4는 현행 투명 시트에서 분리했고, L3는 승인된 각진 원본을 사용했습니다. 초소는 기존 분리본을 재사용했습니다. 공통 바닥은 승인 PNG를 그대로 보존했습니다. 128px 및 약 300px에서 밝은색·짙은색·초록 배경 합성 검사를 통과했습니다.

**신규 분리 검토본 12개:** 훈련소 구조물 4개, 신당 4개, 화덕 4개. 합쳐진 원화에서 배경·흙바닥·문구를 제거한 AI 보조 분리본입니다. 큰 후광이나 잘못 추가된 구조는 수정했지만, 나뭇결·끈·불꽃·자잘한 돌과 가려진 부분, 일부 비율은 원화와 차이가 있습니다. 픽셀 동일 추출 또는 최종 승인 에셋으로 간주하지 마세요.

최신 지시에 따라 훈련소 전용 원형 바닥은 제외하고 승인 공통 사각 바닥을 사용합니다. 훈련소 L2 목재의 배치 배율은 앞선 시안 대비 0.8입니다. PNG 자체는 원본 해상도를 보존했으며, manifest에 배치 기준을 기록했습니다. Figma의 아래 표시도 수정된 상단과 동일한 구조물 하단 190px 기준으로 맞췄습니다. 게임 배치 시에는 접지점과 크기를 다시 검증해야 합니다. 신당의 토대 돌·제단, 화덕 내부의 재와 돌은 시설 자체의 일부로 남겼고 외부 마름모 바닥·길과는 분리했습니다.

기존 길 참고본은 주변의 부드러운 번짐과 연결부 검증이 남아 있습니다. 새로 승인된 길 교체본이 아닙니다.

## 사용 기준

- [Figma B10000](https://www.figma.com/design/zkbflw9fCdAlWbphhw5pSS?node-id=1099-62)에서 각 원화 아래 개별 PNG를 볼 수 있습니다. 아래 미리보기는 각 단계의 위 원화 표시 크기·정렬에 맞췄으며, 게임 내 크기나 점유 면적은 아닙니다. 원화에 포함된 흙바닥을 분리했으므로 신당·화덕의 가로 폭과 실루엣은 원화 전체와 픽셀 단위로 같지 않습니다. 원본 PNG는 [`assets/buildings/separated-v003`](../../../assets/buildings/separated-v003/)의 파일을 사용하세요.
- 신당은 320×280 표시 칸에서 높이 166→184→202→222px, 가로 중앙 160px·하단 264px로 단계 성장감을 맞췄습니다. 화덕은 상단 L1·L2의 90% 조정을 반영한 표시 경계 안에 종횡비를 유지해 맞췄습니다.

- 건물·공통 사각 바닥·길을 별도 레이어로 유지하세요.
- manifest의 기준점은 표시용 임시 값입니다. 격자 중심, 접지점, Y-sort, 충돌 범위와 점유 크기는 게임 적용 시 검증해야 합니다.
- 미세한 저알파 잔여색은 합성 검수에서 큰 문제를 보이지 않았지만, 엔진 필터링·밉맵·줌별 검증은 하지 않았습니다.
- 별도 외부 그림자 PNG나 애니메이션 프레임은 포함하지 않았습니다. 객체 내부 명암은 유지했습니다.
- 4단계 움집 흰천 시안은 승인 여부가 확인되지 않아 사용하지 않았고, 현행 Figma L4를 유지했습니다.
