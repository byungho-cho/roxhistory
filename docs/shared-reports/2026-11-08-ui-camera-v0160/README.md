# 0.1.60 UI·카메라 수정

2026-11-08, MY-NUROX. 이전 0.1.59 메모에 이어 요청한 수정 반영.

- 업그레이드 비용 HUD를 연 상태에서도 드래그·휠·핀치 카메라 이동/확대가 가능하며 선택 건물을 따라간다. 제스처로 구매·주인공 이동이 발생하지 않는다.
- 개발 속도 옵션은 모든 건설·업그레이드 총 5초. 기존 ON 저장의 speed10 작업도 완료 비율을 유지하며 fixed5로 이관한다. 옵션 전환은 진행 비율을 보존한다.
- 퀘스트 창을 Figma 1479:76 기준 1280×720 배치로 정렬했다. 원본 이미지의 투명 여백을 반영하고 진행바 높이를 12px로 맞췄다. 퀘스트 후속 임무·보상 지급은 여전히 미완성 초안이다.
- 퀘스트바 내부 10px 여백, 주민 말풍선은 실제 문장 길이에 맞는 폭과 세로 정렬을 적용했다.
- 캐릭터 안내 닫기에 실제 크림색 원형 X 아이콘을 적용했다(1636:7295, 기존 v034 에셋).
- 건설·이동·업그레이드에는 명시적 취소 아이콘이 있다. 비용/진행바 몸체는 공통 확대 비율을 쓰고, 확인·취소 아이콘은 화면상 44px를 유지한다.
- 일반 확인 팝업은 하단 큰 실행 버튼 하나, 상단 X와 바깥 영역은 취소다. 바깥 터치가 월드에 전달되지 않는다. 공사 취소 팝업의 X/바깥 터치는 공사를 유지한다.
- Figma는 읽기만 했으며 사용자 첨부 원본과 서명 키는 수정하지 않았다.

## 검사

Windows Godot 4.5.1에서 모델 192, 고정 5초 55, 주민 시나리오 24, HUD 안내 45, Windows 회귀 48, UI 검토 22, 기존 UI 18, 신규 카메라/팝업 UI 34개 통과. building_polish 오류 배열도 비어 있다. 신규 UI 검사는 합성 터치를 사용했으며 Android 실기기 검증은 남아 있다. 과거 state_tests448의 알려진 실패 전체를 해결했다는 의미는 아니다.

검사 로그는 D:\devtools\roxhistory-checks\v0160-*에 보존한다. 대표 실행 캡처는 evidence 폴더에 있다. 캡처의 빨간 마을 경계는 개발 설정 ON에 따른 표시다.
