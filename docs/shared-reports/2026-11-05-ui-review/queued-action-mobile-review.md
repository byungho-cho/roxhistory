# Queued action indicator and mobile control fixes

Replaced the action-reserved toast with a noninteractive 26px existing icon above the hero: wood, stone, construction hut, movement, or the existing generic gather icon for an untargeted gather request. Only the last pending action is displayed; execution, cancellation and clearing remove it. Modal/map/background states hide it without altering the queue. The indicator avoids existing seed rewards and the family dialogue rectangle. No dedicated family invitation icon exists in the current mapped assets, so that reservation stays functional without a substitute symbol. Queue behavior and save data remain unchanged.

Mobile code defects independently reproduced/fixed: placement confirm/cancel and the family invitation bubble used plain Button with touch-to-mouse emulation disabled; replaced with the game's existing DemoButton. Synthetic InputEventScreenTouch press/release now cancels and confirms through viewport GUI dispatch. Radial-menu placement now clamps its full height above the actual action-row top, including portrait layout, instead of using a fixed bottom offset that could overlap the row.

Validation: 15 queue presentation/state checks and actual rendered wood/build icons; 14 mobile touch/layout checks (including separate family mouse/touch paths and exactly one signal per gesture) across 1280x720, 720x1280 and 1080x2400. These are desktop/synthetic checks, not Android device verification. No unsupported workaround was used. The second screenshot's exact reported layout remains unverified; the independently identified portrait overlap is fixed.
