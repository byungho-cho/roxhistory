## 보존 기준

저장 초기화 없이 기존 자원·주택·보상·가족 합류 상태를 유지한다. 기존 가족 합류는 주민 집 3채 완료 후 발생하는 흐름을 보존한다. 리소스 교체로 충돌체나 점유 규격은 변경하지 않는다.

## 미확정 및 추가 에셋

- 건설비: 나무 20개 + 돌 20개 적용. 기존 주택의 실제 지불 비용은 저장값을 유지해 철거 반환에 사용.
- 새 2D 주인공의 방향별 걷기·채집 모션은 제공되지 않음.
- 월드맵 지형의 자연스러운 반복 이음새와 확장 타일은 제작·검증 필요.
- Windows 내보내기와 시작·종료 확인 완료. Android는 최신 사용자 요청에 따라 이번에 제작·배포하지 않았다.

## 구현과 남은 차이

- `game/data/assets.json`에서 ID·원본 경로·출처·크기·해시·기준점·크롭·연결 위치를 관리한다. `AssetCatalog.set_replacements()`는 로컬 리소스 교체를 허용하고 누락/크기 불일치 시 기본 파일을 사용한다. 다운로드 기능은 없다.
- 주인공 집 1채 + 주민 집 최대 5채, 1단계 움집 원본 사용. 이전 스타일 기록은 삭제하지 않았으며 단계 업그레이드는 구현하지 않음.
- 토대와 길은 PNG 텍스처로 분리. 건설된 집 사이에만 1칸 길을 표시한다. 현재 토대 접지와 길 경계의 시각적 품질은 추가 검토 필요.
- 나무 4개·바위 3개를 직접 채집, 소/중/대 2/3/5회, 매회 10개. 기존 재생성 30초를 유지하며 재생성은 건설 후보지 밖의 접근 가능한 위치를 사용한다.
- 기존 가족 합류는 주민 집 3채 건설 시 해금하는 동작을 유지했다. 주인공 포함 3채가 아니라 총 4채 시점이다.
- 월드맵 배경은 Figma의 반사 반복 크롭을 유한 영역으로 구성. 산·냇물·호수 원본을 재사용했으나 산과 냇물 연결·반복 지형의 자연스러움은 미완료다. 무한 타일 확장으로 검증한 것이 아님.
- 마을/월드맵 이동 시 진행 중 행동은 일시 정지 후 복귀한다. 입력 해제와 버튼 입력 분리 적용.
- 기존 3D 주인공·동물과 모션 유지. Figma의 2D 주인공 시안과 동일한 표현은 아님. 설정 버튼·미니맵 장식 등 HUD 세부도 원화와 차이가 남아 있음.
- 저장 초기화나 삭제는 하지 않았다. 테스트는 격리 프로필에만 작성했다.
