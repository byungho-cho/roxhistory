# v0.1.33 Windows 검토본 · 건설 미리보기·메뉴·승인 지형

2026-11-04 KST. 기준 main 837dc8a. APK는 사용자 요청으로 보류하며 Windows 단일 EXE만 제공합니다. Android 최종 설치·업데이트 검증은 이번 라운드에서 수행하지 않았습니다. 기존 v0.1.32 APK는 유지합니다.

## 실제 반영

- 새 확정 원화 749:403과 흐름743:428의 실제 Figma 렌더를 확인했습니다. Figma 파일은 수정하지 않았습니다. [원화](approved-art.png).
- 건설 → 움집 → 후보지 → 반투명 미리보기 → 확인/취소. 340월드px 움집이 2.4초 주기로 ±3px 움직입니다. 충돌 없는 임시 노드이며 비용/저장/보상은 확인 전 변경하지 않습니다. 확인 후 원격 건설2초, 기존 비계/먼지/진행/완료 효과 유지.
- 작업 중 확인하면 한 칸 예약에 추가하며, 새 유효 요청이 교체합니다. 미리보기만 선택하거나 취소하면 이전 예약을 바꾸지 않습니다. 확인 시/예약 실행 시 부지를 재검사합니다. 중복 확인·중단·화면전환·수동 이동에서 유령건물/중복차감 없음.
- 조이스틱은 현재 작업·예약 취소 후 즉시 이동. 건설비1+1, 씨앗10, 채집1.2초, 철거 비용10이하전액/초과90%내림, 주민유지 규칙 보존.
- 펼침: 기존 채집·제작(미구현 비활성)·임무·가방을 왼쪽 보조 영역에 두고 건설과 접기 버튼을 오른쪽에 배치. 기존 승인 아이콘·돌 받침·화살표/메뉴 이미지를 재사용합니다. 접힘은 건설+메뉴만 남기는 **최소형 제안**입니다. 처음에는 펼친 상태이므로 기능을 숨기지 않습니다. 작은 버튼도 최소44×72 논리px 터치 영역을 확보합니다.
- 논리960×540 기준 펼침384×72, 접힘112×72. 물리1280×720에서는 각각512×96, 약149×96px. 조이스틱은 줌과 무관하게 유지. 화면비별 측정은 검사JSON 참조.
- 시작 소리 아이콘은 v32 그림 크기의0.7 **제안값**. 1600×900 기준190.08→133.056px, 1280×720 기준152.064→106.445px. 터치영역220→220 디자인px(1280에서176px) 유지. 음량/음소거/BGM 코드 변경 없음.
- 씨앗 수령 여부를 실제 건물 상태로 판단해 모두 받은 뒤에는 패널/상세에서 수령 요청을 반복하지 않습니다. 재접속·기존 저장·중복 수령 검사. 가족 콘텐츠/안내 추가 없음.
- 사용자 승인 새 지형을 원본 바이트 그대로 반영했습니다. [출처·배치·강 경계](terrain-source.md). 기존 마스크/바위 충돌을 제거하고 나무4개·장식 바위2개를 독립 에셋으로 배치했습니다. 채집 자원 수량·보상·재생성 규칙은 변경하지 않았습니다.
- 나무/바위의 실제 몸통/바닥 충돌과 Y순서 가림은 별도 처리. 바위와 나무가 제거된 지점의 통행, 자동 경로, 6개 후보지, 물 경계 검사 완료. 기존 주인공 모델·초상화·보행 보존.

## 검증

- Godot4.5.1 / Windows / NVIDIA RTX5060 / OpenGL. 화면 밖 독립 테스트 창 및 합성 입력. 사용자 PC 조작을 자동으로 제어하지 않았습니다.
- 전체36묶음 통과. 미리보기92항목, 새 지형32항목, 기존 예약28항목. 자산141개 해시 검사 통과.
- 가로1280×720, 커버 비율896×370, 펼침 비율816×616, 추가 세로540×960 레이아웃. 실제 폴드 기기 결과가 아닙니다.
- 저장·재로드·보상·철거·취소·예약·메뉴반복·앱중단/복귀는 네이티브 검사. 소리아이콘 그림과 터치영역은 각각 측정.
- Windows 최종 내보내기 및 실행 확인은 아래 전달 기록에 추가합니다. Android APK는 만들거나 배포하지 않습니다. CI도 명시적인 수동 build_android 요청 없이는 APK를 내보내지 않도록 했습니다.

## 남은 시각적 차이와 미검증

- 미리보기 확인/취소는 기존 테마를 이용한 동적 UI이며 원화의 붉은 X/초록 체크 버튼과 질감이 완전히 동일하지 않습니다. 기존 아이콘을 유지한 메뉴의 보조 항목은 원화보다 많고 돌 받침 형태가 다릅니다. 접힘 구성과0.7 소리아이콘 크기는 PC 검토 후 판단할 제안입니다.
- 새 지형은 생성형 편집본이므로 기존 땅무늬/강변의 픽셀이 다릅니다. 단순 원본 레이어 복원이라고 표시하지 않습니다. 먼 산림·강변 자갈은 배경에 남아 있습니다.
- 실기기 터치, Android 업데이트, 직접 청취, 장시간 발열/성능은 이번 검증에 포함하지 않았습니다. Windows 코드 서명 인증서는 적용하지 않았습니다.
