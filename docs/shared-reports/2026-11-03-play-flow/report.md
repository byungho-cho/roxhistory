# S40000 플레이 흐름 교정 — 0.1.20

기준일 2026-11-03 KST. 최신 main `12d477a`(PR #38 문서·주민 원화 포함)에 작업을 통합했습니다. 기존 패키지 `com.roxhistory.demo`, 서명, 저장 형식을 보존합니다. 생성일자는 실행일이 아니라 이 버전의 제작일입니다.

## 반영

- 첫 실행·시작 화면에 `버전 0.1.20 · 생성일자 2026.11.03`. Android code21.
- 작은 상단 중앙 토스트, 왼쪽 초상화/정착지 진행/퀘스트, 우측 상단 나무·돌·씨앗, 우측 하단 접힘·펼침/상황별 행동. 미구현 체력·레벨 대신 실제 정착지 진행을 표시합니다.
- Figma 507:53의 접힘/펼침 구성을 게임 컨트롤로 연결. 저장된 S40000 아이콘 PNG를 재사용합니다. 자원칸은 평소 75% 불투명도, 획득 후 5초간 100%, 이후 완만하게 복귀합니다.
- Ctrl+휠은 커서 중심 확대. 터치 핀치 중 월드 탭을 차단하고 UI 크기를 고정합니다.
- 자원 터치 → 충돌을 피한 경로 이동 → 접촉 자세 → 1.2초 채집. 수동 입력·다른 대상·핀치·중단 시 취소. 지급은 저장 성공 뒤 한 번만 실행합니다.
- 최초 기존 움집 1채, 퀘스트 신규 3채. 각 나무1+돌1, 현재 건설2초. 터치/건설 버튼에서 확인 팝업 없이 시작합니다. 형태는 각 1/3 확률로 한 번 선택해 저장합니다.
- 완료 팝업 제거. 완성 건물 위 씨앗 표시 → 건물 터치 시 10개 확정 저장 → 상단 씨앗칸으로 입자 이동 → 숫자 증가. 재진입·중복 터치에도 한 번만 지급됩니다.
- 커다란 채집 범위 대신 자원 바로 아래 작은 빛과 표식을 사용합니다. 연기는 기존보다 선명하게, 개별 물고기는 각기 다른 위상과 꼬리 변형을 적용했습니다.
- 동물은 기존 실제 3D 모델의 호흡·고개/먹이 동작을 재질의 부드러운 형태 변형으로 추가했습니다. 걷는 발 리그는 아래 잔여 범위입니다.
- 새로 시작은 진행만, 완전 초기화는 진행/보상/백업/설정/첫 실행 상태를 모두 초기화합니다. 검증은 `--test-ui` 임시 저장에만 수행했습니다.

## 검증과 증거

Windows Godot 4.5.1 / RTX5060, 고정60 시뮬레이션의 22개 검사 묶음 **1,480개 통과**. [검사별 결과](local-tests.json). 자산 127개 크기·해시, 음원15개 검사도 통과했습니다. 기존 팝업을 누르던 검사는 새 월드 보상 동작으로 바꾸되 취소/중복/저장 검증을 유지했습니다.

Android15/API35 x86_64 읽기 전용 에뮬레이터 1280×720에 업데이트 설치. 실제 MotionEvent 입력으로 새게임, 자동 이동·나무/돌 채집, 직접 건설, 중복 보상, 중단/복귀, 핀치를 확인했습니다. 생산 저장 파일의 SHA-256은 전후 동일했습니다. [Android 상태 증거](android-loop.json).

## 남은 품질 범위

- 동물은 고개/호흡/먹이 동작 1차 변형입니다. 관절 리그를 갖춘 자연스러운 걷기·배회는 미완료이며 정지 메시를 이동시키는 방식으로 대체하지 않았습니다.
- UI의 기능·배치는 반영했으나 Figma 원화와 픽셀 단위 동일한 결과는 아닙니다. 전체 지도/구름 경계 재구성은 이번 변경에 포함하지 않았습니다.
- 실물 Android·폴드 기기, 장시간 발열/프레임률과 주인공 보행 체감 검토는 미검증입니다. 주민 8종 원화는 보존했고 새 주민 시스템은 추가하지 않았습니다.

## 자산·수정 책임

원본 `design/assets/s40000/v001/game/` → 게임 `game/assets/ui/s40000/`, 원본 PNG는 편집하지 않고 알파 영역을 AtlasTexture로 표시합니다. 움집/환경/동물 원본과 기존 출처·조건 기록은 해당 design 폴더에 보존합니다. 연기·물고기 원본은 `game/assets/effects/`, 추가 움직임은 `game/shaders/fish_motion.gdshader`, `wildlife_motion.gdshader`입니다.

경로: `auto_travel.gd`; 입력: `world_gestures.gd`; 거래/이전 저장 호환: `game_state.gd`·`save_store.gd`; HUD/보상 이동: `play_chrome.gd`; 환경: `world_ambient.gd`·`world_animal.gd`. Windows 단일 실행 파일용 기존 export preset도 유지했습니다.

최종 병합 소스·APK 해시·직접 다운로드는 이 폴더의 `release.json`과 GitHub v0.1.20 릴리스에서 제공합니다.
