- 전체 지도 맞춤 1배~2배 확대, Ctrl+휠·핀치 중심 확대, UI/조이스틱 크기 고정. 별도로 그린 최소/최대 원화의 움집 크기를 비교해 범위를 정했다.
- 기존 Git UI 아이콘 재사용, Figma에서 접기 X·금색 초상화 프레임 직접 추출. 원형 메뉴·접힌/펼친 행동 목록·왼쪽 퀘스트·반투명 자원 표시를 정리했다. 건설 버튼은 월드 건물 축소판이 아닌 승인된 컨트롤 아이콘이다.

- 완성된 움집마다 3개 연기 입자가 상승·확산·소멸. 승인된 물고기 이미지 5마리가 강 안에서 이동하고 꼬리가 움직인다.

## 남은 차이와 한계

원화는 별도 그림이므로 단순 카메라 확대만으로 모든 오브젝트 위치와 픽셀이 완전히 일치하지 않는다. 상단은 실제 씨앗을 포함한 3자원, 왼쪽 바는 구현된 정착 진행을 표시한다. 원화의 장식용 체력/레벨 시스템을 새로 만들지 않았다. 새 게임은 한 채이며 건설 후 채워진다.

동물은 자동 리깅+절차적 동작으로, 전문 애니메이터가 만든 보행 클립 수준의 발 접지/방향별 변형은 추가 다듬기가 필요하다. 주인공 보행도 관절/접촉 자동 검증과 실제 프레임은 확인했지만 최종 자연스러움은 사용자 검토가 남는다. 실물 Android/폴드, 장시간 발열·성능, 동일 기기 조건 전후 성능 수치는 미검증이다. 기존 living_map 테스트는 검사를 통과했으나 종료 시 ObjectDB 누수 경고가 남으며 이번 변경에서 새로 발생한 것으로 확인되지는 않았다.
