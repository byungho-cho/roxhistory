## 적용 내용

- 시작 화면은 이어서 하기 / 새로 시작 / 설정. 장 선택은 새로 시작 확인 이후에만 표시합니다. 현재 구현된 장은 1장이고, 새 게임을 실제 시작하기 전에는 기존 진행을 교체하지 않습니다.
- 진행 초기화와 완전 초기화는 설정의 개발 설정으로 이동했습니다. 두 작업 모두 확인이 필요하며, 진행 초기화는 소리 설정을 유지합니다. 설정 행을 줄이고 ON/OFF 대비를 높였습니다.
- 건축물 개수 제한 해제 스위치를 추가했습니다. 기본 OFF, 저장 후 이어하기에도 유지됩니다. 건설자 무제한과 독립입니다. OFF는 주민 움집 1/2/3/3채, 화덕·신당 각 1개를 적용합니다. 공사 중인 건물도 한도에 포함합니다. ON은 이 개수 제한만 해제하며 본부 단계·자원·자리·저장 안전 상한은 유지합니다. OFF로 돌아와도 초과 건물을 지우지 않습니다.
- 본부가 없을 때 건설 버튼은 본부 배치로 진입합니다. 본부는 일반 사이드 메뉴에서 제외했습니다. 본부 완공 후 기존 해금 단계에 맞춰 다른 건물을 건설합니다. 화덕/훈련소는 본부 2단계, 신당/초소는 3단계라는 최신 개발본 기준을 유지했습니다.
- 사이드 메뉴 비용을 제거하고 배치 미리보기 하단에 Figma의 붓터치 이미지와 목재·석재 실제 비용을 표시합니다. 이동 미리보기에는 건설비를 표시하지 않습니다.
- 업그레이드는 확정된 공통 화살표를 재사용하고, Figma 석재 비용판과 O/X 확인 메뉴를 적용했습니다. 기존 단계별 비용·시간은 변경하지 않았습니다.
- 공사 10배속 변경은 이미 지난 진행률을 유지합니다. 진행바 X는 확인 후 실제 지불 자원 전액을 한 번만 반환합니다. 완료 시각이 지난 작업은 환급하지 않고 완공 처리해 완료/취소 경합을 방지합니다.
- 건물 지붕부터 밑면까지 선택합니다. 기존 이동 버튼 클릭→위치 선택→확인/취소를 유지하며, 이동 버튼 0.5초 길게 누르기→드래그→손을 떼고 확인/취소를 추가했습니다.
- 마을과 월드맵 모두 PC 휠 버튼 드래그로 카메라를 이동합니다. 일반 휠과 Ctrl+휠 확대·축소를 모두 지원합니다. 카메라 드래그를 캐릭터 이동 탭으로 처리하지 않습니다.
- 야생동물 충돌체는 건설 검증에서 제외하고, 확정한 부지에 겹친 동물은 주변의 유효한 육지로 옮깁니다. 주민·나무·바위·건물 충돌은 유지합니다.
- 퀘스트는 금색 강조선과 자원 행 구조로, 주민 말풍선은 짙은 초록 바탕·금색 제목·밝은 안내의 2행 구조로 정리했습니다. 수용 공간 부족 시 실제 대기 인원과 빈자리, 움집 건설/업그레이드를 안내합니다.
