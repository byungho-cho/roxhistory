# RoxHistory 0.1.56 건물 조작과 단계별 효과

2026-11-07. 기준 소스는 Windows 검토 브랜치 `375f266`이며 원격 동일 상태를 확인했습니다. main `ed31a1c`는 이 브랜치의 선행 커밋입니다. 사용자 요청에 따라 이번 산출물은 Android APK입니다. 패키지 `com.roxhistory.demo`, versionCode 57, versionName 0.1.56을 사용합니다.

## 반영 사항

- 건물 자체를 0.65초 길게 누르면 이동 미리보기로 전환합니다. 잡은 위치와 건물 바닥의 상대 위치를 보존합니다. 손을 떼면 확인·취소 상태를 유지하며, 짧은 클릭은 기존 메뉴입니다. 메뉴의 이동 버튼도 클릭으로 계속 사용할 수 있습니다.
- 업그레이드 메뉴 바깥 클릭·터치로 닫습니다. 해당 입력은 이동 명령으로 전달되지 않고 비용도 지불하지 않습니다. 비용바 크기는 원복한 기존 디자인을 유지했습니다.
- 진행바 X가 축소된 부모 영역 바깥에 있고 다른 UI가 겹치는 경우에도 자신의 클릭·터치를 받도록 입력 소유권을 분리했습니다. 취소 확인 후 환급하는 기존 규칙을 유지합니다.
- 배치 중 여러 빈 후보지의 말뚝 가이드를 숨깁니다. 선택한 건물 미리보기와 유효성 표시, 확인·취소는 유지합니다.
- 씨앗 보상이 남은 건물의 몸체를 클릭해도 메뉴보다 수령을 먼저 처리합니다. 다음 클릭부터 메뉴를 표시하며 중복 지급하지 않습니다.
- 화덕 1~4단계에 원본 불꽃 부분만 움직이는 셰이더와 불·연기를 추가했습니다. 단계에 따라 크기와 강도가 증가합니다.
- 신당 3~4단계는 기존 새김 문양을 따라 연두·금색 빛이 맥동합니다. 4단계는 조금 더 밝고 작은 입자가 추가됩니다.
- 훈련소 2단계부터 사각 토대 아래쪽에 작은 2D 인물의 창 훈련과 약한 먼지를 추가했습니다. 2단계는 한 쌍, 3~4단계는 두 쌍입니다. 디자인 리터치 시 별도 효과 레이어의 위치만 바꿀 수 있습니다.
- 철거 확인 후 기존 건물 이미지를 약 1.5초 유지하면서 좌우 망치와 흙먼지를 표시하고 마지막에 사라지게 했습니다. 철거와 반환은 최초 확인에서 한 번만 저장하며, 표시 중 종료해도 중복 반환되지 않습니다.

## 10배속 확인 결과

현 기준 소스에서는 오류가 재현되지 않았습니다. 실제 설정 버튼을 클릭해 ON으로 전환한 뒤 새 건설이 60초 대신 약 6초 후 완료되는 것을 Windows 실행 검사에서 확인했습니다. 2단계 업그레이드는 600초 대신 60초, 4단계는 10800초 대신 1080초입니다. 진행 중 공사도 ON 전환 시 남은 시간이 1/10로 환산되며 저장 후 유지됩니다. 타이머는 이미 단축된 실제 잔여 초를 표시하므로 숫자가 10씩 내려가는 방식은 아닙니다. 배속 계산 자체는 바꾸지 않았습니다.

## 시각 자료와 구현 위치

[단계별 효과 6초 영상](building-effects.mp4)과 [단계 비교](effects-stages.png)는 실제 게임 에셋과 효과 코드를 실행한 효과 검토 장면입니다. 마을 전체 플레이 영상은 아닙니다. [철거 실행 캡처](demolition.png)는 실제 플레이 화면입니다.

기존 `game/assets/buildings/approved-v001/`와 `game/assets/effects/construction-hammer.png`를 재사용했습니다. 신규 외부 에셋은 없습니다. 효과는 `building_life_effects.gd`, `demolition_effect.gd`, `shaders/hearth_flame.gdshader`로 분리되어 있습니다. 훈련 인물은 작은 기호형 2D 표현이며 정식 캐릭터 모션은 아닙니다. 불·빛·연기의 최종 강도는 모바일 확인 후 추가 조정할 수 있습니다.
