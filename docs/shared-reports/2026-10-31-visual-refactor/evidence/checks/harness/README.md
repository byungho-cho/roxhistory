# Android 검증에 실제 사용한 보조 스크립트

현재 Windows PC/SDK와 읽기 전용 임시 AVD에 맞춘 실행 기록입니다. 범용 테스트 배포 도구가 아닙니다. 작업 폴더에서 실행했고 `visual-evidence/`, 이전/현재 APK, scrcpy, 미리 생성한 MultiTouch 주입 도구가 필요합니다.

모든 게임 조작은 `--test-ui`의 분리 저장을 사용했습니다. `normal-save-preserved.json`은 비교용 원래 저장 사본이며 사용자 진행 정보여서 이 폴더에 포함하지 않습니다. 비교 fixture는 합성한 테스트 상태입니다.

`android_ready.py`는 실제 제목 화면 준비 확인, 저장 교체 중 잠깐 파일이 없는 경우의 제한된 재조회/해시 검증, 실제 조이스틱 이동과 일시정지 위치 확인을 제공합니다. 조이스틱 중심144/582와 뒤로가기68/65는1280×720 화면 기준입니다. 시작 위치·자원 지급·취소·중복·저장 판정 조건을 낮추지 않았습니다.

검사 출력과 시각 검토 결과는 상위 폴더 JSON 및 보고서에 구분했습니다. 화면 비율 검사는 `wm size` 모사이며 실물 폴드 기기 검사가 아닙니다.
