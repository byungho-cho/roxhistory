생성 PNG 자체가 수정 가능한 래스터 원본이다. 레이어가 분리된 PSD나 새 Blender 원본을 제작한 것은 아니다. 기존 PNG/2D 시안/모델 생성 코드는 보존했다. 외부 스톡이나 타사 모델 라이선스를 새로 도입하지 않았다. 생성 출력과 기존 프로젝트 입력 자산은 각각 해당 서비스와 프로젝트의 기존 사용 조건을 따른다. 이미지별 파일 크기·SHA-256은 `game/assets/manifest.json`에 기록했다.

## 제작 지시 요약

아래는 생성 도구에 전달한 지시의 요약이며 원문 전문은 아니다.

- 지형: 카메라·강둑·지형 연결 유지. 작은 풀·돌 무늬와 흰 포말을 줄이고 저채도 잔디·넓은 부드러운 흙길. 건물·주인공·UI를 배경에 추가하지 않음.
- 움집/나무: 동일한 비스듬한 시점·따뜻한 좌상단 빛. 둥근 큰 형태·낮은 묘사 밀도, 독립 투명 자산.
- 목재: 지면에 누운 실제 작은 통나무 두 개, 서로 다른 각도와 절단면, 얇은 접촉 그림자. 묶음·바닥 판·UI 기호 없음.
- 돌: 원래 돌 무리 구도 유지, 둥근 무광 회갈색 큰 면, 강한 이끼색/발광 제거. 후속 배경 제거 생성은 번짐을 해결하지 못해 채택하지 않았고, 첫 편집 결과의 반투명 가장자리를 런타임 재질에서 정리했다.

## 공통 시각 기준과 수정 책임

- 대표 좌표 `(1060,1030)`, 기본 카메라 유지. 모든 전후 비교는 같은 위치·비율·배율을 사용.
- 대표 움집 폭 400 / 나무 290 / 작은 전경 나무 210 / 목재 96 / 돌 108 월드 단위. 낮은 움집 입구는 선사시대 작은 정착지 표현이며 실내 출입 기능은 없다.
- 독립 이미지의 알파 0.5 이상 외곽을 측정해 아틀라스와 바닥 기준점을 맞춤. 원본 픽셀은 보존. 그림자 색은 `SceneStyle.SHADOW`로 공유.
- `SceneStyle`: 자산·공통 크기/그림자. `DemoWorld`, `EnvironmentProp`: 배치·충돌·접지·바람. `HybridCharacter` 계열: 실제 3D 모델/관절/동작. `WorldFeedback`: 접촉·파편. `PlayChrome`: 헤더·획득 비행. `WorldGestures`: 터치 소유권/핀치. `DemoSoundscape`: 환경음·음소거·생명주기.
- 물 셰이더는 파란/청록 영역만 움직여 마른 강둑의 흔들림을 피한다. 잎/풀의 위상은 유지하고 진폭만 낮춘다.
- 강물 음원은 v0.1.7의 조용한 흐름 생성 방식 재사용. 새 녹음과 음소거/중단 검증 결과는 본 보고서에 분리 기록한다. 실제 청취 승인을 수치 검사로 대체하지 않는다.
