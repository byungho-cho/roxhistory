최신 main과 로컬 검토 모델·미반영 작업을 대조하고 별도 브랜치에서 진행합니다. 이미 반영된 항목은 보존하고 누락·차이만 수정합니다.

**1. 작업 방향과 우선순위**

사용자가 높게 평가한 **나무·움집의 모습과 기존 배경을 유지**합니다. 이번에는 주인공 외형과 버튼·패널을 최초 시안에 가깝게 맞추는 데 집중합니다.

작업 우선순위는 다음과 같습니다.

1. 지정 원화에 맞는 3D 주인공 외형 제작·검토.
2. 대기·이동·회전·작업 애니메이션과 게임 적용.
3. 첫 실행·게임 시작·터전 선택·플레이 UI 교정.
4. 앱 아이콘·강물 음량 수정과 Android 통합 검증.

기존 이동·채집·건설·보상·저장은 보존합니다. 주민·동물·새 지역·전투·성장 시스템은 후속 범위로 유지합니다.

**2. 주인공의 기준 원화와 표현 방향**

C001의 **‘01. 원화 · 채색 시안 v0.3’**에 실제 삽입된 정면·후면·좌측면·우측면 이미지를 기준으로 합니다.

이번 원화의 특징은 다음과 같습니다.

- 풍성하고 불규칙하게 겹치는 갈색 머리카락과 묶은 머리.
- 큰 눈과 밝은 표정, 귀엽지만 활동적인 신체 비율.
- 갈색 가죽과 밝은 털 장식이 겹친 비대칭 의상.
- 허리끈·매듭, 손목 보호대, 발목 장식과 가죽 신발.
- 따뜻한 색감과 부드러운 명암, 손으로 채색한 듯한 재질.

이전 문서의 밝은 단벌 가죽옷 등 외형 설명은 **이번 원화의 실제 형태·색·장식에 맞춰 갱신**합니다. 이전 탐색 이미지의 특징을 섞어 다른 캐릭터로 바꾸지 않습니다.

**2D 배경과 실제 3D 주인공 구성을 유지하며, 최대한 애니메이션 작품 같은 인상으로 제작합니다.**

**3. 실제 3D 모델 제작 기준**

현재 1차·2차 모델에서 재사용 가능한 부분을 확인하고, 원화를 재현하기 어려운 부분은 재제작합니다.

- **얼굴:** 둥근 볼·턱, 생기 있는 눈, 자연스러운 코와 입, 밝은 표정을 표현합니다.
- **비율:** 원화의 머리·몸통·팔다리 비율을 따릅니다. 머리 크기만 키우거나 몸을 가늘게 만드는 방식으로 단순화하지 않습니다.
- **머리카락:** 앞머리·옆머리·뒷머리의 흐름과 겹침을 조형합니다. 반복되는 같은 모양의 덩어리가 규칙적으로 둘러진 느낌을 줄입니다.
- **신체:** 어깨·팔꿈치·손목·무릎·발목이 자연스럽게 이어지고 움직일 때 틈이나 급격한 꺾임이 드러나지 않도록 합니다.
- **의상:** 가죽과 털의 겹침, 비대칭 장식, 옷자락·허리끈·손목·발목 장비를 반영합니다.
- **재질:** 피부·머리·가죽·털의 차이를 표현하면서 원화의 부드러운 채색을 유지합니다. 과한 광택과 플라스틱 같은 인상을 줄입니다.

원화의 네 방향 사이에 세부 불일치가 있으면 얼굴과 전체 실루엣을 유지하면서 실제 입체 구조가 일관되도록 정리하고 변경점을 기록합니다.

전달물에는 **게임용 `.glb`, 수정 가능한 모델 제작 원본, 텍스처, 리그와 애니메이션 원본**을 포함합니다. 사용한 자산의 출처·사용 조건도 기록합니다.

**4. 애니메이션풍 동작과 게임 적용**

외형과 함께 몸의 무게·동작의 리듬·상태 전환을 다듬습니다.

- 대기 중 호흡·눈 깜박임·작은 고개 움직임.
- 이동 속도와 보폭이 맞는 걷기.
- 모든 이동 방향에서 자연스럽게 이어지는 회전.
- 출발·정지·급회전 시 자세의 부드러운 연결.
- 준비 → 접촉 → 회복이 읽히는 채집·건설 동작.
- 도구를 쥔 손과 어깨·몸통·무게중심의 연동.
- 발 미끄러짐과 지면 관통, 도구와 대상의 접점 보완.

캐릭터 전체를 같은 주기로 흔드는 표현에 의존하지 않고 신체 부위별 역할과 움직임을 구성합니다. 머리카락·끈·옷자락의 보조 움직임은 필요한 범위에서 적용합니다.

기존 입력 반응성과 이동 속도를 보존하고, 애니메이션 전환 때문에 조작이 늦어지지 않도록 합니다. 작업 취소·완료 후에는 자연스럽게 대기로 복귀합니다.

초상화도 새 주인공과 동일한 얼굴·머리·의상 인상으로 맞춥니다.

**5. 캐릭터 검토와 완료 판단**

인계받은 2차 모델은 품질 검토 중인 자료이며, 최종 외형 확정이나 게임 적용 완료로 취급하지 않습니다.

새 원화 기준으로 다음 자료를 먼저 제시합니다.

- 원화와 같은 크기·방향으로 비교한 정면·측면·후면.
- 입체 형태를 확인할 수 있는 사선 화면.
- 실제 게임 배경에 배치한 기본 크기와 확대 화면.
- 대기·이동·정지·회전·채집·건설의 원속도 영상.

원화 재현도, 머리카락의 자연스러움, 신체 볼륨, 의상 표현, 작은 화면에서의 가독성을 구분해 검토합니다. 외형 제작·실행 검증·사용자 품질 판단을 각각 기록합니다.

**6. 앱 아이콘과 강물 음량**

- APK 앱 아이콘은 사용자가 전달한 **움집 이미지**로 교체합니다.
- Android 아이콘 마스크 적용 후에도 움집이 잘리거나 지나치게 작아지지 않는지 확인합니다.
- 강물 전용 음량을 현재 배포 버전 설정 대비 **약 절반 수준으로 낮춥니다.**
- 다른 효과음과 전체 마스터 음량은 유지합니다.
- 실제 청취로 확인하고 기존 음소거 설정·앱 중단·복귀 동작을 보존합니다.

**7. 첫 실행 안내 화면**

사용자가 제공한 첫 실행 시안에 형태·색·질감·글꼴·아이콘·간격을 맞춥니다.

- 기존 숲·강·움집 배경 활용.
- 중앙의 어두운 반투명 패널, 암각화 장식, 움집 로고 적용.
- 제목: **당신의 여정이 시작됩니다**
- 본문은 다음 두 줄로 표시:
  **강가의 작은 터전에서**  
  **나만의 이야기를 만들어 보세요.**
- 왼쪽 버튼: **소리 없이 시작**
- 오른쪽 버튼: **소리 켜고 시작**
- 하단 문구: **소리 설정은 게임 안에서 언제든 바꿀 수 있습니다.**

버튼 선택과 실제 소리 설정·저장이 일치하도록 합니다.

**8. 게임 시작 화면**

사용자가 제공한 두 번째 시안에 맞춥니다.

- 왼쪽 위 로고와 소개 문구.
- 오른쪽 **이어하기 / 새로 시작 / 장 선택** 패널.
- 오른쪽 위 소리 버튼.
- 왼쪽 아래 현재 장 표시.

기존 배경·저장·이어하기 기능을 보존하고 버튼 상태와 실제 동작을 연결합니다.

**9. 첫 터전 선택 화면**

지도 배경을 유지하면서 지역 표식과 우측 상세 패널을 시안에 맞춥니다.

배치 조정은 다음 기준으로 적용합니다.

- 전곡리·암사동·동삼동 버튼의 시각적 크기를 현재보다 **약 20% 축소**.
- 동삼동 버튼은 **축소 전 버튼 폭의 40%만큼 왼쪽으로 이동**.
- 동삼동 버튼의 세로 위치는 유지.
- 축소된 버튼에도 누르기 편한 터치 영역 확보.

우측에는 지역 이미지·이름·설명과 **이곳에서 시작** 버튼을 배치합니다. 다른 지역의 신규 플레이 콘텐츠로 범위를 확대하지 않습니다.

**10. 실제 플레이 화면 UI**

**좌측 상단**

시안의 캐릭터 초상화·프레임·이름·레벨·에너지 등 상태 표시를 맞춥니다. 표시값의 기존 데이터 연결 여부를 확인하고 미연결 항목은 보고서에 구분합니다.

이번 요청은 화면 표시이며, 레벨 성장이나 에너지 소비 규칙을 새로 도입하지 않습니다.

**우측 상단**

자원 아이콘·수량 표시줄과 원형 미니맵을 시안의 위치·크기·색감·프레임에 맞춥니다. 실시간 지도 동작과 표시 데이터는 현재 구현을 확인하여 연결하고, 추가 기능 범위는 구분합니다.

**하단**

- 중앙: **사냥 / 채집 / 제작 / 건설**
- 우측: **두루마리·가방 모양 원형 아이콘**

형태·아이콘·글꼴·간격·선택 상태를 시안에 맞춥니다. 외형 교정을 신규 전투·제작·인벤토리 시스템 개발로 확대하지 않습니다. 현재 사용할 수 있는 행동과 미연결 행동의 상태를 구분합니다.

**퀘스트 상자**

시안의 ‘멧돼지를 추적하라’ 상자 형태를 사용하고, 내용은 현재 건설 목표로 표시합니다.

**움막을 지어라.**  
**돌 1개, 나무 1개**

재료 수집·건설 진행·완료 상태와 안내를 일치시킵니다. 멧돼지 추적 퀘스트는 추가하지 않습니다.

**11. 통합 검증과 유지 조건**

기존 핀치 확대·축소, 목표 구역 안내, 채집·획득 연출 등 이미 동작하는 기능을 보존합니다.

데모 조건은 다음과 같습니다.

- 나무 1개 + 돌 1개.
- 자원별 각 1회 채집으로 건설 가능.
- 채집 1.2초, 건설 2초.
- 기존 보상 1회와 저장·이어하기 규칙 유지.

Android에서 첫 실행 → 게임 시작 → 터전 선택 → 이동·채집 → 건설·보상 → 종료·이어하기를 확인합니다. 확대·축소, UI 입력, 작업 취소·중복 입력, 앱 중단·복귀도 검증합니다.

같은 구도의 전후 캡처와 소리 포함 실행 영상을 제공합니다. 커버·펼침 화면의 가독성·터치 영역·잘림을 확인하고 실기기와 에뮬레이터 결과를 구분합니다.

**12. 문서와 최종 전달**

보고서와 모델·비교 증거를 저장소에 정리하고 `docs/shared-reports/`의 공유 인덱스를 갱신합니다. 원화와 모델 제작 원본·게임 적용 파일의 위치를 연결합니다.

Figma와 로드맵에는 수정 요구·구현·검증·품질 검토 상태를 구분하여 기록합니다. 앞으로 새로운 캐릭터 이미지가 필요하면 피그마에서 직접 생성·정리하는 방식을 우선하며, 지정 원화는 기준으로 보존합니다. PDF는 새로 만들지 않습니다.
