## 반영

- 퀘스트 바·초상화·체력·자원·고정 메뉴·채집/건설 진행 표시의 표시 순서를 정리했다. 주민 배정 말풍선이 이 영역과 겹치면 해당 버튼 전체를 숨겨 그림과 클릭 우선순위가 일치한다. 고정 HUD와 겹친 공사 취소 X도 입력을 가로채지 않는다. 접힌 메뉴의 빈 칸은 불필요하게 가리지 않는다.
- 자연물은 선택 직후 이동 중부터 예약한다. 나무/돌 공통이며 주인공의 이동·현재 채집·다음 작업 예약도 같은 소유권을 사용한다. 다른 채집자가 예약한 대상은 선택/채집할 수 없다. 완료·취소·경로 실패·직업 변경·주민 이탈/노드 제거 시 해제한다. 일시정지는 예약을 유지하며, 예약 정보는 저장 파일에 쓰지 않는다.
- 주민의 채집 이동·운반·복귀는 공통 이동 코드에 0.5배 배율을 적용한다. 주인공 기본 속도와 주민의 한가한 산책·짐 없는 보초 이동은 유지한다. 채집/수확1.2초는 변경하지 않았다. 농부의 이동에도 같은 주민 작업 이동 배율이 적용되지만 농장 생산·에셋·메뉴 코드는 변경하지 않았다.
- 흙길은 기존 원본의 흙 질감을 재사용하되 최소1.4칸/기준1.6칸의 길 몸체와 불규칙한 부드러운 가장자리를 적용했다. 가깝게 연결하는 네트워크와 둥근 굽이로 기존 병렬 직각 길을 줄였다. 고정 월드 좌표로 질감을 이어 반복 사각 무늬를 제거했다. 건물 위치·충돌·실제 이동 경로 데이터는 변경하지 않았다.
- 화덕 원본을 변형하던 UV 셰이더를 제거했다. 별도 CPUParticles2D의 불꽃·밝은 불꽃 중심·불티가 움직인다. 원화에 이미 그려진 불꽃은 고정된 상태로 남고, 움직임은 독립 파티클에서 만든다. 원본 PNG는 수정하지 않았다.
- 훈련소의 작은 선/점 그림 대신 기존 주민 캐릭터 메시와 연습용 창으로 찌르기·팔/상체 전환 동작을 넣었다. L1은1명, L2~L4는2명이다. 표현 전용이며 일반 주민 수·직업·전투 로직에 포함하지 않는다. 일시정지·공사 중 숨김과 화면 밖 렌더링 제한을 적용한다.
- 미배정 주민이 서서 쉴 때 하품·기지개·졸기 동작을 기존 캐릭터 뼈대로 적용한다. 주민별/휴식 주기별 타이밍을 엇갈리게 하고 이동·작업을 시작하면 해제한다. 주인공의 기존 동작은 유지한다.
- 사당 L3는 붉은 주황빛, L4는 파란빛으로 구분했다. 선폭·광채·불티 대비를 높였으며 원본 돌 이미지는 변형하지 않는다.

## 0.1.64 추가 메모 반영
