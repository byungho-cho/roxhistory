- 이동 속도 **151.25 → 181.5 (+20%)**. 기존 15뼈대에 저장된 실제 Animation 클립(30트랙×65키)을 적용했습니다. 발을 든 뒤 앞으로 보내고 디디는 키를 편집했고 보폭은92→104로 연결했습니다. 이동 거리로 위상을 진행하므로 프레임 수에 따라 발만 빨라지는 구조가 아닙니다. 작업 모션·도구·대기·회전은 기존 동작을 유지합니다.
- 움집 바닥 충돌을 좁은 직사각형에서 처마 아래의 8점 발자국 형태로 수정했습니다. 배치·입구·가림 기준은 유지합니다. 양옆 조이스틱 진입과 건물 반대편 자동 경로를 검사했습니다.
- Android는 **가로 고정**으로 되돌렸습니다. 기존 저장·카메라·핀치·드래그 코드는 보존합니다.
- 기존 주인공 모델·리깅을 재사용한 여성/건장한 남성 **주민 2명 시범**. 16,000삼각형, 1024px 텍스처의 파생 GLB, 개별 휴식·배회 주기. 유료 생성·외부 서비스 전송 없음. [편집 원본·출처·제약](../../../art-source/resident-prototypes/README.md).

## 남은 품질 차이 / 미검증

- 주민은 시범이며 성인 얼굴·맨발·복장과 머리 실루엣이 승인 원화 수준에 못 미칩니다. [참고/편집 원본](../../../art-source/resident-prototypes/README.md). 실제 주민 생활 시스템은 추가하지 않았습니다.
- 근거리 채집은 제자리 입력을 우선했습니다. **상호작용 범위 가장자리 및 일부 방향에서는 도구와 자원 사이 간격이 남을 수 있습니다.** 자원 반응 좌표와 도구 좌표를 따로 측정하며 완전한 접촉 해결로 보고하지 않습니다. 손 IK/작업 자세의 후속 아트 조정이 필요합니다.
- 새 보행은 저장된 키프레임 클립이지만 전문 모션캡처가 아닙니다. 어깨·옷 변형과 발 미끄러짐의 최종 체감 승인은 비교 영상으로 확인해야 합니다.
- 실물 폴드/휴대폰, 직접 청취, 장시간 발열·배터리·성능은 미검증입니다. 에뮬레이터 화면 비율과 자동 검사 통과는 실기기 사용성·최종 시각 승인을 대신하지 않습니다.
