# 검토 순서

1. `a303-before-*`와 `a303-*-full/selected`는 동일 1600×900 실제 실행 전후 화면이다.
2. `figma-*`, `a303-target-dongsam`은 승인 시안의 Figma 내보내기다.
3. `*-overlay`는 50% 겹치기, `*-diff-x4`는 절대 RGB 차이 4배 강조다. 품질 점수가 아니다.
4. `android-region-*`는 실제 Android 에뮬레이터 캡처다. 커버/펼침은 표시 크기 모사이며 실기기가 아니다.
5. `region-selection.mp4`는 지역 선택·이동·확대·핀치·복원 원속도, `android-play-loop.mp4`는 채집·건설·보상 원속도다. 관찰 시점은 상위 보고서에 있다.
6. JSON은 자동 검증 결과, signature/package는 전달용 APK의 서명·패키지 검사다. 최종 다운로드 해시는 릴리스 본문을 따른다.

일반 저장 내용, 계정·인증 정보, APK 중간 산출물은 포함하지 않았다.
