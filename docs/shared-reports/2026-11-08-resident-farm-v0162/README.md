# 주민 활동·농장 0.1.62 확정 운반 규칙 반영

기준 main: 0682825 (0.1.61). 이번 사용자 답변으로 수확마다 운반·이탈 주민 짐 즉시 반환을 확정했다. 0.1.61의 초안 상태는 이전 보고서에 보존한다. Figma는 읽기만 했고 사용자 화면·첨부 원본·기존 서명 자료는 변경하지 않았다.

## 구현

- 일반 주민 직업: 미배정·농부·나무꾼·석재꾼·보초. 촌장·별도 건설자는 일반 주민에 포함하지 않는다. 일반 주민과 표시 수용 인원 최대15명. 움집 1·2·3·5명 수용 유지, 일반 건설 한도는 촌장집 L1~L4별 1·2·3·3채. 기존 초과 소유는 삭제하지 않는다.
- 촌장집 말풍선/상단 주민 수 → 전체 배분, 개별 일 선택, 농장/초소 선택. 건물마다 1명, 다른 주민이 차지한 건물은 선택 불가. 농장·초소의 상시 말풍선으로 직접 재배정/해제. 전체 배분과 같은 저장 데이터를 사용한다. 직업별 예시 숫자를 고정 한도로 사용하지 않았다.
- 보초는 지정 초소까지 이동해 대기한다. 전투·탐지는 추가하지 않았다.
- 주민과 주인공은 ActorMovement의 속도·목적지 방향 계산·충돌 이동 함수를 공유한다. 나무·돌은 기존 자연물별 charges와 5~10분 재생을 유지하며 1회10개/1.2초. 마지막 잔량은 저장 트랜잭션으로 경쟁 처리한다. 채집 중에만 짧은 동작 진행바를 보이며 잔량을 농장식 성장률로 표시하지 않는다.
- 목재·석재는 가장 가까운 주민 움집의 접근 가능한 입구까지 실제로 걸어가서 한 번만 지급한다. 촌장집 입금·고정 운반 시간은 제거했다. 기존 저장된 운반 짐은 유지한다. 배정 변경 시에도 기존 짐부터 전달한다.
- 농장은 주민 움집1채 후 해금. 일반 한도는 촌장집 L1~L4별 1·2·3·3개, 초소 최대3개. 기존 개발 설정의 개수 제한 해제는 계속 적용된다.
- 농장 L1~L4 비용 목재10·20·30·50, 석재5·10·20·30. 건설/업그레이드 시간1분·10분·30분·3시간과 개발 ON의 총5초, 취소/100%환급·건설자 정책을 기존 공통 경로로 재사용한다.
- 농장 준비60초와 성장600초를 분리. 생산량5·10·24·40, 수확1·2·3·4회, 매회1.2초로 자동 수확한다. 수확1회마다 곡식 짐을 만들고 가까운 주민 움집으로 운반한 뒤 농장으로 돌아와 다음 수확을 한다. 1회 운반량은 L1~L4별5·5·8·10개이며 총1·2·3·4번 왕복한다. 마지막 수확으로 잔량0이 되면 다음 준비로 이어진다. 짐이 있는 동안 다음 수확은 불가능하며 도착 전에는 잔고에 지급하지 않는다. 준비는 농부 배정 필요, 이미 자라는 곡식은 미배정이어도 성장하고 수확은 농부를 기다린다.
- 움집 철거 확인에 이탈 인원을 사전 표시. 확인 시 초과 인원만 무작위 선정해 배정을 해제한다. 주민 ID는 재번호하지 않아 생존자의 직업/짐이 바뀌지 않는다. 마지막 움집이면 일반 주민 전원 이탈, 촌장 유지. 철거 저장 실패 시 집·주민·자원 모두 보존한다.
- 씨앗 잔고를 grain(곡식)에 같은 값으로 이관하고 원래 tokens 값과 claimed 플래그도 보존한다. 새 구리 잔고를 분리했다. 움집의 기존 씨앗 수입 지급은 중지하고, 미정인 구리 수입량·주기를 임의로 만들지 않았다.
- 일반 설정에 건축 완료·업그레이드 완료·새 주민 합류 알림의 미설정/ON/OFF를 저장한다. 저장 성공 후 이벤트를 내보내는 구조를 연결했다. 자동 수확 알림 없음. OS 권한·전달·반복 정책은 연결하지 않았다.

## 확정 정책과 남은 사항

| 항목 | 기존 | 이번 개발 빌드 / 남은 결정 |
| --- | --- | --- |
| 수확 횟수와 운반 왕복 대응 | 0.1.61은 보관 후 정책 대기 | **확정: 매번 운반.** 한 번 수확→실제 이동→가까운 움집 입금→농장 복귀→다음 수확. 적재·작물 잔량 변경은 원자적으로 저장하고 입금은 한 번만 처리 |
| 종료 중 생산 | 주민 채집은 종료 중 실행 안 함. 건설은 기존 절대 시각으로 완료 | 농장도 활성 시뮬레이션 누적만 저장. 재시작 시 성장 시간/수확분은 보존하고 종료 시간 소급 생산은 하지 않음. 최종 정책 대기 |
| 이탈 주민의 운반 짐 | 0.1.61은 held_cargo 보관 | **확정: 즉시 반환.** 떠나는 주민의 목재·석재·곡식을 철거 트랜잭션에서 마을 잔고에 반환하고 짐/배정을 제거. 저장 실패 시 주민·집·잔고 모두 그대로 보존 |
| 농장 철거 시 보관 곡식 | 농장 없음 | 보관 곡식을 held_cargo로 이동해 삭제 방지. 최종 지급/회수 정책 대기 |
| 구리 수입 | 움집 완료 씨앗10 지급 | 기존 잔고·획득 이력 보존, 구리 수입 수치·주기·최종 외형 대기 |
| 알림 | 별도 구조 없음 | 기본값 미설정. ON/OFF 저장과 모델 이벤트까지만 연결. OS 전송·반복·최종 기본값 대기 |

모달·지도·비활성 상태에서 주민 활동/농장 활성 시간은 기존 주민 시뮬레이션처럼 쉰다. 종료 중 건설 완료는 기존 동작을 유지한다. 위 보류 상태는 기획 확정으로 간주하지 않는다.

## 임시 외형과 Figma

기획 근거: [주민 통합](https://www.figma.com/design/zkbflw9fCdAlWbphhw5pSS?node-id=1647-8), [일 배정](https://www.figma.com/design/zkbflw9fCdAlWbphhw5pSS?node-id=1673-8), [조건표](https://www.figma.com/design/zkbflw9fCdAlWbphhw5pSS?node-id=1686-14). 병행 수정 중이므로 이번 사용자 지시의 확정 수치가 앞선 초안의 미정 문구보다 우선한다.

- game/assets/placeholders/farm.svg: TEMP FARM 표시가 있는 코드로 그린 개발 전용 밭. 최종 투명 농장 에셋이 아니다.
- FarmPlotVisual: 공통4단계 임시 줄기, L1~L3 성기게/L4 풍성하게, 하단 검정 붓터치·성장바·남은 시간. 최종 곡식 분리 그림으로 교체 필요.
- 건물 배정 말풍선은 공통 색과 주민 아이콘으로 임시 조합. 최종 말풍선/보초 화면 에셋 및 배치는 병행 기획 후 대조 필요.
- 주민·곡식·초소 아이콘은 해당 Figma 응답의 분리 원본을 로컬에 저장. 공통 종이 팝업·X·목재/석재·선택 갈색 배경은 기존 에셋 재사용.
- 농부 수확 동작은 기존 주민 작업 모션을 임시 재사용한다.
- 석재소·제재소, 추가 L3/L4 효과, 보초 전투는 추가하지 않았다. 후속 퀘스트/보상도 이번 범위에 포함하지 않았다.

## 검사와 실행

모델131, 건설 회귀192, 5초 시계63, 실제 주민 왕복24, 카메라/팝업 회귀34, 새 UI27개 통과(총471). 새 UI에는 건물 말풍선의 합성 터치, 배정 동기화, L4 농부의 실제4회 왕복/총40개 순차 입금, 철거 경고 비잘림, 720px 높이의 주민15명 목록에서 변경 버튼 위 터치 드래그로 끝까지 스크롤하는 검사를 포함한다. 화면 크기 변경 시 모달이 닫히는 기존 동작은 유지된다. Android 실기기 확인은 별도이며 기존 모든 legacy 검사가 통과했다는 뜻은 아니다.

외부 검사 로그: D:\devtools\roxhistory-checks\farm-*.log. 대표 캡처는 evidence/. 로컬 빌드는 scripts/build-release.ps1, 동일 커밋의 APK/EXE 배포는 scripts/publish-release.ps1로 검증한다. 버전0.1.62 / Android versionCode63. 기존 서명 키를 재사용하며 새 키를 만들지 않는다.

실행 위치:
- D:\workspace\roxhistory\build\Roxhistory_0.1.62.exe
- D:\workspace\roxhistory\build\Roxhistory_0.1.62.apk

빌드 시 서명·정렬·Windows 실행 검사와 두 파일 해시를 build/release-manifest.json에 기록한다. 기획 중인 항목은 남아 있으므로 최종 농장 완성판이 아닌 개발 확인용이다.

빌드 보완: Windows 실행 검사는 --test-ui로 별도 테스트 저장 경로를 사용한다. 기존 스크립트가 기본 저장을 읽던 경로를 격리했다. 기존 0.1.58 창은 임의로 종료하지 않았으며 새 버전 실행 전 기존 창을 닫아야 동시 저장 덮어쓰기를 피할 수 있다.

이번 버전에는 일반 주민 배분/일 선택/직접 배정에도 기존 터치 스크롤 구현을 재사용했다. 드래그로 행 버튼이 눌리지 않는다. 이전 로컬 개발 저장의 농장 stock 복구 API는 보존하되 정상 생산은 각 수확을 즉시 운반 짐으로 전환한다. 농장 외형·곡식 모션·배정 말풍선은 여전히 임시이며 종료 중 생산/구리 수입/OS 알림은 미정이다.
