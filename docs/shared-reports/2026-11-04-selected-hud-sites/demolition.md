# 철거·간단 안내·타이틀 버튼 보완 — 2026-11-04

기준 건설 커밋 `fb0a36f`. 기존 배포 v0.1.30 이후 작업 브랜치의 추가 구현이다. 아직 이 문서만으로 Android 배포 완료를 뜻하지 않는다.

## 적용 동작

- 사용자가 지은 움집을 0.65초 길게 누르면 짧은 질문, 예상 반환, 취소/철거 두 버튼만 있는 중앙 확인창을 연다. PC 마우스와 터치에 동일하게 적용한다. 드래그·핀치·UI 입력은 철거로 넘어가지 않는다.
- 확인창 열기/취소/바깥 클릭은 저장과 자원을 변경하지 않는다. 앱 중단은 확인을 폐기한다. 일반 작업은 확인창에서 잠시 멈추고 취소 후 이어진다. 실제 이동 명령은 기존대로 작업을 취소한다.
- 실제 지불한 자원별 비용이 10 이하이면 전액, 10 초과이면 90%를 계산한다. 현재 나무1/돌1은 각각1 반환. 자원 반환과 건물 삭제를 한 번의 검증된 저장으로 처리하며 성공 후에만0.32초 건물 페이드와0.85초 바닥 먼지, 반환 알림을 표시한다. 연출이 중단되어도 저장된 환급은 재실행하지 않는다.
- 건물마다 안정적인 식별자를 저장해 같은 확인을 반복하거나, 같은 부지에 재건축한 뒤 옛 확인을 실행해도 중복 환급되지 않는다. 기존 저장의 배열 순서에 의존하던 위치는 `legacy_slot`으로 보존한다. 남은 움집의 위치·외형·수령 상태가 바뀌지 않는다.
- 삭제된 건물의 그림과 충돌체를 함께 정리한다. 부지는 다시 사용할 수 있고 주민 인스턴스는 유지한다. 기본 세계 건물 `ExistingHut`는 대상에서 제외한다.
- 미수령 씨앗이 있는 건물은 먼저 짧게 눌러 정상 수령하도록 안내한다. 철거가 보상을 임의 지급하거나 이미 얻은 보상을 삭제하지 않도록 한 보존 조치다. 기존 보상량과 수령 방식은 변경하지 않았다.
- 첫 보금자리 소개 모달 없이 바로 플레이한다. 기존 `intro_seen` 저장 필드는 호환을 위해 유지한다. 수동 안내성 하단 컨텍스트와 반복적인 건설 후 안내 문구는 숨긴다. 자원 부족·경로 실패·저장 오류·소리 설정·실제 환급 등 필요한 메시지와 건물 보상 아이콘은 유지한다.
- 타이틀 뿔피리 영역은 디자인 좌표88×88에서176×176으로 변경했다. 우측 여백 안으로 이동하며 기존 음소거·설정·재생 함수를 그대로 쓴다.

## 미래 비용의 소수 처리

현재 데모 비용에는 소수가 발생하지 않는다. 비용10은10 반환,20은18 반환이다. 비용11→9.9,15→13.5 등의 미사용 미래 비용은 정책 승인 전 철거를 거절하고 안내한다. 9/13으로 잘라 지급하지 않는다. 제안은 자원별 1/10 단위 잔여를 저장하고 정수 도달 시 합산하는 방식이며, UI 예상량과 실제 지급/잔여량을 함께 보여줘야 한다. 이 정책은 아직 구현·확정하지 않았다.

## 시각 보완과 원본

- 프로필은 기존 `game/assets/ui/s40000/portrait.png`의 얼굴 픽셀을 그대로 사용하고, 코드의 실루엣 마스크로 불필요한 금색 원형 프레임을 제외했다. 초상화 내용·3D 주인공·보행은 바꾸지 않았다.
- 메뉴 받침은 확정 Figma3안의 원본을 `game/assets/ui/s40000/approved-option3-reference.png`에 보존하고 돌 부분 `(832,852,42,14)`를 UV로 재사용한다. 원본 위치는 파일 `zkbflw9fCdAlWbphhw5pSS`, 노드 `702:334/335`다. 새 이미지 생성이나 유료 크레딧 사용은 없다. 작은 부분을 확장한 받침이므로 원화의 전체 굴곡·질감과 완전 일치한다고 주장하지 않는다.
- 에셋 목록은138개 크기/SHA-256 검사를 통과했다. 기존137개 파일은 변경하지 않았다.
