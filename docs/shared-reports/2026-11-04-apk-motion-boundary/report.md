## 시각 판단과 한계

- 화면 캡처에서 원래 지형이 넓게 드러나고 뒤집힌 나무 반복은 제거됐음을 확인했다. 바깥 경계는 새 지형 원화가 아닌 색상 연장이므로 색 번짐이 남는다. 참고 이미지와 동일한 최종 아트로 승인된 상태가 아니다.
- 뼈 궤적 검사는 통과했지만 원화와 보행 품질의 최종 시각 승인은 별도다. 고정 104 월드 단위 보행 주기와 3D→2D 투영 때문에 방향별 발 미끄러짐이 완전히 해결됐다고 주장하지 않는다. 원본 스킨/모델은 교체하지 않았고 유료 생성도 하지 않았다.
- 실물 Android/폴드 터치·직접 청취·장시간 성능은 미검증이다.

## 이미지 접근 때문에 보류

현재 도구 목록에 Library `prepare_materialize`가 없고, 작업 환경에서 Library 스킬 및 `references/materialization.md`를 찾지 못했다. 전달받은 16개 Library ID의 실제 픽셀을 열지 못했다. 임의 URL/다른 다운로드 방식으로 우회하지 않았다.

- 지정 버튼 하나만 배경·테두리 제거: 대상 픽셀 미확인.
- 지정 팝업만 배경 클릭에 유지: 대상 팝업 미확인.
- 씨앗 보상 말풍선 3안: 채택 이미지 미확인. 현재 보상/지급 동작 보존.
- 두 화면 BGM 연속 재생: 정확한 화면 두 개 미확인. 기존 음악/음소거/백그라운드 동작 보존.
- HUD·하단 메뉴의 새로운 세부 시각 교정 및 참고 구름 재현: 이미지 확보 후 진행. 코드상 오른쪽 보조 화살표는 메뉴 펼침·접힘 전용이며, 큰 활성 버튼은 근처 채집/건설 또는 메뉴 동작을 수행한다. 둘 다 실제 기능이 있어 임의 삭제하지 않았다.
- 넓은 검정 안내/추가 PC 안내는 지정 이미지를 확인한 뒤 범위를 확정한다. 명시적인 PC 확대 안내만 이번에 제거했다.

**현재는 독립 범위 수정본이다. 전체 요청 완료·최종 릴리스 배포 완료가 아니다.** 이미지 의존 작업, Android 검증 결과와 최종 릴리스 링크는 확정 후 갱신한다.
