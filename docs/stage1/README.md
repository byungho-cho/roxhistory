# 1단계: 암사동 강변 배경·오브젝트

이 PR은 1단계만 다룹니다. 캐릭터 애니메이션, 채집·건설 연출, 환경음, UI 전면 개편은 다음 단계입니다. 사용자 시각 검토 전 병합하지 않습니다.

## 장면과 에셋

Godot 4.5.1 / 2D Compatibility 렌더러를 유지했습니다. 기존 퀘스트의 자원 7곳·수량·건설 터·보상·저장 스키마를 유지합니다. 기존 저장 위치가 새 오브젝트 안에 있으면 가까운 빈 땅으로 복원합니다.

| 구분 | 에셋 / 용도 |
| --- | --- |
| 재사용 | `game/assets/characters/villager.png`, UI atlas `20204.png`, 금빛 화살표, Noto Sans KR, 메뉴·지도 원본 |
| 플레이에서 교체 | 인물·동물·건설 장면이 박힌 `98398.png` 대신 지형 전용 `environment/terrain.png` |
| 신규 개별 오브젝트 | `tree.png`, `shrub.png`, `grass.png`, `hut.png`, `rock.png`, `props.png` |
| 재사용한 월드 자원 | 나무 atlas 아이콘을 발밑 기준으로 배치. 돌은 신규 바위 에셋. 채집 대상에는 바닥 링과 남은 수량을 표시 |
| 동적 환경 | 별도 물 Polygon2D의 잔물결/반사광 셰이더, 나무·버들 관목·풀의 위상·속도가 다른 바람 셰이더 |

원본 생성 이미지는 그대로 보존하고 AtlasTexture의 불투명 영역 기준 사각형으로 투명 여백만 제외합니다. 모든 오브젝트는 바닥 접점을 원점으로 배치합니다. 부모 월드의 Y 정렬로 캐릭터·나무·지붕의 앞뒤 가림을 처리합니다. 충돌은 나무 밑동·건물 바닥·바위의 발자국에 맞추며, 강물과 강둑 충돌은 같은 경계 좌표를 사용합니다. 밝은 배경 위 제목에는 외곽선을 보완했습니다. 강·마을·건설 터를 함께 보여주도록 카메라 시야만 조정했습니다.

Figma 기준: [플레이 화면 110:495](https://www.figma.com/design/zkbflw9fCdAlWbphhw5pSS?node-id=110-495). 기존 아기자기한 2.5D·둥근 형태·따뜻한 좌상단 빛·자연 재질을 유지하되, 사용자 요청대로 한 장의 콘셉트 아트를 실제 배치 오브젝트로 바꿨습니다. 디자인 파일 자체는 수정하지 않았습니다.

움집 지붕이 지면에 닿는 형태는 [강동구 신석기 주거 설명](https://www.gangdong.go.kr/web/culture/contents/gdc020_020_010)을 참고했습니다. 생활 소품은 빗살무늬 토기·갈돌/갈판·식물 섬유 그물로 한정했습니다. 게임 장면은 역사 복원도가 아닙니다.

## 생성 기록

내장 imagegen 도구 사용. 프롬프트와 시각 기준은 [asset-prompts.md](asset-prompts.md). 원본 파일의 바이트 수·SHA-256은 `game/assets/manifest.json`에서 검증합니다. 생성 이미지 7개는 모두 프로젝트에 저장했습니다. 외곽 광택 제거 편집 시도 2개는 채택하지 않았으며 원본을 대체하지 않았습니다.

## 후속 검토

- 캐릭터는 기존 임시 4방향 이미지/상하 움직임을 유지합니다. 2단계에서 대기·이동·행동 애니메이션을 개선합니다.
- 정적 지형의 작은 자갈·낮은 지피식물은 배경 디테일이며, 이동/충돌이 필요한 나무·건물·바위·소품은 별도 노드입니다.
- 물은 평면 잔물결 표현이며 유체 시뮬레이션이 아닙니다. 보급형 실기기 GPU·발열·장시간 플레이는 별도 확인이 필요합니다.
- UI 전면 재설계, 소리, 채집·건설 효과, 전체 퀘스트 품질 마감은 이번 단계에 포함하지 않습니다.
