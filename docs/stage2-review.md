## 구현과 시각 검토

- 기존 4방향 그림과 세분 메시 보행·호흡·채집·건설을 재사용했다. 새 캐릭터나 주민을 추가하지 않았다.
- 정지 순간 보행 자세가 즉시 사라지던 것을 약 0.11초 가중치 전환으로 보완했다. 걸음 주기는 실제 이동 거리에만 따라가며 막힌 상태에서는 멈춘다.
- 다리 중앙의 변형 가중치를 연속적으로 바꿨다. 도구는 추정한 별도 회전 좌표 대신 그림의 손과 동일한 변형 함수를 사용한다. 옆 방향 도구가 얼굴·가슴 쪽을 가로지르던 궤적을 바깥쪽으로 수정했다.
- 건설 터 북쪽에서는 건물이 생길 때 끼는 것을 방지하는 기존 입구 조건을 유지하고, 아래쪽 입구로 이동하라는 안내를 추가했다.
- [실제 엔진 근접 영상](stage2/character-review.mp4)과 네 방향 캡처를 검토했다. 손·도구 밀착, 정지·재이동, 앞뒤 가림을 확인했다. 메시 방식은 새 프레임이나 분리 파츠 리깅이 아니며 옆걸음과 임시 도구 그림의 표현 한계는 남는다.

## APK와 서명

v0.1.2-stage2 / versionCode 3 / com.roxhistory.demo / arm64-v8a + x86_64. GitHub Release에는 서명 APK 단일 파일만 별도 제공한다. 최종 소스 커밋·CI·다운로드 해시는 PR #8과 Release에 기록한다.

팀장 로컬 P2 실험 APK의 키를 재사용하고 저장소 밖에 보존했다. 인증서 SHA-256: `cf65aeecb4e399ba9e2e6b9fa947f34f8c31bd75c8e3b686ad29d8431bb1695f`. 기존 로컬 P2 APK 위 `adb install -r` 성공. 같은 키의 보완본 업데이트 전후 저장 파일 해시가 동일해 기존 재고가 보존됨을 확인했다. 건물·보상은 별도 종료/이어하기 검사에서 복원을 확인했다.

**P1 공개 Release v0.1.1-stage1과는 서명이 다르므로 덮어쓰기 설치 불가.** P1 CI는 실행마다 임시 키를 만들었고 그 개인 키는 이 로컬에 없다. P1 삭제 후 설치하면 앱 저장도 지워지므로 진행을 보존해야 하는 기기에서는 먼저 저장 백업을 준비해야 한다. 기존 P1 데이터는 실기기에서 삭제하지 않았다. CI APK는 임시 키의 검증 산출물이며 이번 Release는 위 보존 키로 서명한 APK다.

## 상태와 후속

P2는 **보완 중 / 기술 검증 통과 / 아트 최종 판정 대기**. P3는 미착수이며 후속 범위는 자원 타격 반응·획득 효과·건설 단계 연출이다. 실기기, ARM GPU, 물리 폴딩, 발열·배터리·장시간 성능은 미검증이다.

로드맵 JSON·Markdown·6쪽 PDF와 기존 FigJam의 P2 문구를 맞췄다. 기존 Library PDF 링크는 과거 스냅샷으로 구분하고 최신 PDF는 저장소 파일로 연결한다. 원래 roxhistory 폴더의 미커밋·미추적 로드맵 작업과 .work/stage2 복사본은 덮어쓰지 않았다.
