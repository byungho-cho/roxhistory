# P2 캐릭터 동작과 짧은 데모 루프

기준일: 2026-10-30 KST. 기준선은 main `1d6628c264dec0b07e506282a04c4bff034fc75e`이며 P1 환경을 보존했다.

## 변경

- 원래 캐릭터의 4방향 그림을 재사용하고 텍스처 좌표를 고정한 세분 메시에서 팔·다리를 독립적으로 굽힌다. 화면 크기를 키우고 방향별 발 위치와 그림자를 맞췄다.
- 이동 거리에 보행 주기를 연결하고 정지·막힌 이동 시 발걸음을 멈춘다. 대기 시 몸통 호흡, 채집·건설 시 팔·도구 동작을 연결했다.
- 이동 입력은 채집을 취소한다. 팝업·앱 중단은 동작과 입력을 정리하고 복귀 시 대기 상태로 돌아온다.
- 사용자 요청으로 움집 비용 나무 1개·돌 1개, 한 번 채집당 1개, 채집 1.2초·건설 2초로 줄였다. 종류별 한 번씩 채집하면 바로 건설할 수 있다. 안내·목표·확인·차감은 공통 설정을 참조한다.
- 기존 저장 형식과 보상 중복 방지는 유지한다. 기존 재고·완성된 집은 보존하며 과거 건설 비용을 소급 환급하지 않는다.
