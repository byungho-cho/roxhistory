구현:
- `duel_skill_hud.gd`: 2 SP 초상화 클릭, 좌하단 반쪽 가로·세로 표시용 배지. 따뜻한 광원은 얼굴을 분리한 투명 초상 뒤에 배치. 진입 0.48초 후 고정.
- 3 SP 독립 연계 버튼은 초상화 가로·세로 80%. 배경광 0.36초 상승 후 유지. 짧은 테두리 광원만 순환하며 이미지·버튼은 흔들거나 축소하지 않음.
- readiness edge를 따로 추적하므로 2→3 SP가 일반 준비광을 재시작하지 않음. 소비·KO·선택 변경·리셋 시 즉시 갱신.
- 터치 캡처와 합성 마우스 차단으로 동일 입력을 두 동작에 전달하지 않음. 손을 버튼 밖에서 놓거나 터치를 취소하면 발동하지 않음.
- 기존 모델 테스트 유지. 1대1 전장 좌하단의 받아치기로 이전 실험실에도 접근 가능.

## 0.2.278 · 2차 보정

- 277의 실제 실패 조건을 재현: SP2+이어도 자동 평타 중 버튼 disabled와 idle-only 가드가 요청을 거절함. 검사에서 idle로 강제 전환하던 경로를 제거하고 평타/접근 중 실제 mouse/touch 입력을 검사하도록 변경.
- 일반/연계 입력은 대기·평타·이동·피격 동작에서 즉시 시전 가능. 진행 중 평타의 예약 contact를 취소하고 현재 위치에서 부드럽게 시전으로 연결. 이미 진행 중인 스킬은 재입력으로 중복 소비하지 않음.
- 일시정지: `advance` 진입에서 시뮬레이션을 정지해 SP/시간/HP/모션/FX/카메라/사망 대기가 같이 멈춤. pause/reset/close UI는 활성. 정지 상태에서 수동 리셋하면 초기 상태로 바뀌되 일시정지는 유지함.
- 본편 1-1의 실제 VS 종료 후 첫 프레임(출전 배치 아님)을 캡처. 본편 `update_camera`를 트리에 넣지 않은 카메라 전용 인스턴스로 재사용. VS 카메라만 프리롤해 첫 전투 프레임의 잔여 줌과 이후 감쇠도 유지. 본편 AI/SP/보상은 실행하지 않음.
- 배치는 Hunt의 HUNTER_BATTLE_CENTER, ALLY_CELLS[0], FORMATION_CENTER, DEER_SLOT을 재사용. 한결 시선은 본편이 전투 시작에 사용하는 heading. RES-050 실험실 모델은 비율을 유지한 채 투영 높이를 본편과 일치시켰음.
- 960x540 기준 첫 프레임: 한결 발(451.6448,291.7658), 꽃사슴 발(588.5052,218.5675), 카메라 scale1.099899/offset(-69.2343,-50.90773)이 본편/실험실에서 같음. 높이도 약70.267/74.287로 일치. 본편은 기존 모델, 실험실은 최신 RES-050이므로 무기 포함 실루엣 너비/자세까지 같다고 주장하지 않음. 비율을 강제로 늘리지 않음.
- 큰 상단 띠/제목/별도 받아치기 버튼 제거. 피그마의 투명 적 아이콘/금테/선택 강조/닫기/리셋/일시정지를 사용. 일반 스킬·연계 준비효과 유지. 작은 아이보리 타이머와 명확한 SP 숫자 적용.
- 새 아군 초상화9종은 미적용. 기존 초상 아틀라스/본편/세이브 데이터/우람 parry clip은 유지.
- 추가 검사 `game/tests/hunt_duel_polish_tests.gd`: 자동 접근 중2/3SP 입력과 중복소비/중단된 평타접촉, 정지/재개, KO0.999/1.000초, 정지 중 수동리셋 포함68개 검사.
