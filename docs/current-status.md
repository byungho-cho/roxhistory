## 현재 구현

상단 토스트·접이식 우측 행동 UI·왼쪽 퀘스트·실제 씨앗 카운터·버전 생성일자, Ctrl+휠, 자원 터치 자동 이동/채집, 최초 움집1+추가3 건설, 팝업 없는 건설/보상, 건물 클릭 시 씨앗 이동·숫자 증가를 반영했습니다. 채집1.2초·건설2초·각 나무1+돌1·보상10입니다. 각 건물의 스타일/수령 상태를 따로 저장하며 이전 단일 건물 저장도 읽습니다.

완전 초기화는 진행과 설정을 지워 첫 실행으로, 새로 시작은 소리 설정을 유지하며 새 지역 선택으로 이동합니다. 검증은 임시 테스트 저장에만 실행했습니다. 기존 패키지·서명은 유지합니다.

연기 강도를 높이고 물고기를 개별 이동/꼬리 변형으로 바꿨습니다. 동물은 3D 원본의 호흡·고개/먹이 변형을 추가했으며 관절 보행 리그와 배회는 아직 미완료입니다. Figma 배치와 원본 UI 에셋을 적용했으나 픽셀 단위 일치, 전체 구름 경계, 실물 Android/폴드·직접 청취·장시간 성능 검토는 남아 있습니다.

이전 릴리스 APK 1개를 새 다운로드 해시 확인 후 정리했습니다. 태그·원본·과거 보고서는 보존합니다.

## 다음 개발 범위와 확인 사항

- 승인 주민을 실제 월드 오브젝트로 연결하고 자연스러운 이동·멈춤·둘러보기·충돌 회피를 구현할 범위를 정리합니다. 원화 승인을 모델·보행 애니메이션 완료로 표시하지 않습니다.
- 동물 보행 리깅, 물고기 개별 동작, 전체 접힘 HUD와 구름 경계는 별도 잔여 작업입니다.
- Android 에뮬레이터에서 채집·건설·보상·중단/복귀·핀치·테스트 저장 유지가 검증됐습니다. 생산용 저장 파일은 빈 파일 상태였으므로 실제 사용자의 유효 진행 저장 검증으로 확대하지 않습니다.
- 실물 Android/폴드 기기, 직접 청취, 장시간·발열과 최종 체감 승인은 남아 있습니다. 날짜나 전체 완성도 백분율은 임의로 확정하지 않습니다.
