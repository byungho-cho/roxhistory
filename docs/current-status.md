## 다음 개발 범위와 확인 사항

- 승인 주민을 실제 월드 오브젝트로 연결하고 자연스러운 이동·멈춤·둘러보기·충돌 회피를 구현할 범위를 정리합니다. 원화 승인을 모델·보행 애니메이션 완료로 표시하지 않습니다.
- 동물 보행 리깅, 물고기 개별 동작, 전체 접힘 HUD와 구름 경계는 별도 잔여 작업입니다.
- Android 에뮬레이터에서 채집·건설·보상·중단/복귀·핀치·테스트 저장 유지가 검증됐습니다. 생산용 저장 파일은 빈 파일 상태였으므로 실제 사용자의 유효 진행 저장 검증으로 확대하지 않습니다.
- 실물 Android/폴드 기기, 직접 청취, 장시간·발열과 최종 체감 승인은 남아 있습니다. 날짜나 전체 완성도 백분율은 임의로 확정하지 않습니다.
