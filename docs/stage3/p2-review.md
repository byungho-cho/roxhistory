# P2 마무리 검토 - P3 착수 전

2026-10-30 KST. 사용자 확정 방향: 기존 2D 배경 + 실제3D 캐릭터 유지. 원본 `villager.png`의 갈색 묶은 머리, 큰 갈색 눈, 밝은 가죽옷, 꼬인 허리끈과 잎 장식을 모델에 반영했다. 이 모델/스킨/모션/장식 형상은 프로젝트를 위해 직접 작성했으며 외부 모델·모션은 사용하지 않았다.

## 먼저 마친 P2 작업
- 둥근 덩어리 머리를 겹쳐진 끝이 가는 머리카락·묶음·끈으로 교체. 얼굴 표면과 눈/입의 깊이를 맞추고 눈 깜박임을 추가.
- 원통형 황토 의상을 밝은 가죽 겹침·끝단·꼬인 허리끈·잎 장식으로 보완.
- 팔·다리를 연속된 스킨 메시 4개로 교체. 팔꿈치/무릎 주변 두 뼈의 가중치를 부드럽게 혼합해 분리된 관절 틈 제거.
- 평지 보행의 무릎·발 회전을 계산해 발바닥이 지면 아래로 내려가지 않도록 조정. 호흡은 상체에 적용하고 정지한 발은 고정.
- 손 뼈에 부착한 도구, 이동 거리 기반 위상, 아날로그 회전, 중단·복귀 유지.
- 반복 장식을 뼈/재질별로 합쳐 별도 메시 제출 수를 줄임. 캐릭터 렌더 해상도384×480, 화면상의 크기는 유지.

기존 캐릭터66, 혼합3D30, 새 스킨·발·중단62, 3D가림13 검사를 통과했다(11:59 UTC / 20:59 KST). 네이티브 Godot4.5.1/RTX5060 실제 렌더로 정면·측면·후면·대각선·채집을 검토했다. 면 방향 오류로 어두워지던 팔/다리를 수정한 후 재검사했다.
