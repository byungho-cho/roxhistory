## 기준의 우선순위

현재 사용자가 제공한 인수인계 지시를 최신 작업 기준으로 사용한다. 이전 문서의 상세안과 충돌하는 내용은 삭제하지 않고 **기존 상세안·재확인 필요**로 기록한다. 이는 이전 논의가 없었다는 뜻도, 상세안을 폐기했다는 뜻도 아니다.

지도 중심, 선사시대 시작, 시대 변화와 한국 지리의 자연스러운 학습은 확정 방향이다. 구체적인 게임 장르·반복 행동·승패·자원·성장·역사 분기는 아직 확정하지 않는다.
