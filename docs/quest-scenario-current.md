## 전체 퀘스트 목록
번호는 기획 순서이며 기존 저장용 quest_id를 임의 변경하는 지시가 아닙니다.

| 번호 | 제목 | 내용 |
| --- | --- | --- |
| 01 | 나무 채집 | 주인공이 나무를 수량에 관계없이 1회 채집. 완료 즉시 목재 +100 자동 지급. 시작 안내창 표시 |
| 02 | 석재 채집 | 주인공이 석재를 수량에 관계없이 1회 채집. 완료 즉시 석재 +100 자동 지급. 시작 안내창 표시 |
| 03 | 촌장집 건설 | 촌장집 최초 완공. 완료 시 곡식 +100 자동 지급. 시작 안내와 일반 건설 해금 안내창 표시 |
| 04 | 첫 움집 | 주민 움집 1채 완공 후 첫 주민 1명 등장. 곡식 +50 수동 수령 |
| 05 | 첫 주민 맞이 | 등장한 주민을 플레이어가 직접 받아들이기. 곡식 +50 수동 수령 |
| 06 | 촌장집 업그레이드 | 촌장집을 다음 단계로 업그레이드. 곡식 +50 수동 수령 |
| 07 | 첫 농장 | 농장 1개 건설. 주민 움집 1개 이상 해금 조건 적용. 곡식 +50 수동 수령 |
| 08 | 농부 배정 | 받아들인 주민을 농장에 농부로 배정. 곡식 +50 수동 수령 |

04 이후는 각 퀘스트 보상 **곡식 +50개**를 **보상 받기 팝업에서 클릭하여 직접 수령**합니다. 자동 지급하지 않습니다. 팝업 진입 방식은 미정이며, 기존 보상 탭 고정 표현은 이 결정으로 대체합니다. 이후 추가 목록은 제안 영역으로 분리하며 확정 목록에 섞지 않습니다. 예를 들어 움집 3채 퀘스트는 촌장집 3단계 이상 조건을 충족한 뒤 배치해야 합니다.

## 첫 시작·보상·안내창
- 새 게임의 목재·석재·곡식은 모두 0개에서 시작합니다. 기존 저장 데이터를 이 규칙으로 소급 초기화하지 않습니다.
- 01~03은 완료 즉시 각각 해당 자원 **100개를 더합니다**. 보유량을 100개로 맞추는 방식이 아닙니다.
- 퀘스트 보상으로 저장 한도를 초과해도 보유량을 그대로 둡니다. 이미 가진 초과분도 버리지 않습니다. 일반 채집의 한도 대기는 별도 규칙입니다.
- 이전의 ‘촌장집 완공 시 모든 자원 100개 지급’ 대신 위 3개 퀘스트별 지급으로 대체합니다. 중복 지급하지 않습니다.
- 01~03에서 이번에 해야 할 일을 캐릭터 **안내창**으로 표시합니다. 별도의 강제 조작 튜토리얼은 보류하고 추후 연결합니다.
- 촌장집 완공 안내 문안 예: “촌장집이 완성됐어요! 이제 다른 건물을 지을 수 있어요. 주민이 머물 움집을 지어볼까요?”
- 안내창은 화면 어디를 눌러도 다음 안내, 마지막이면 닫기. 기존 X 닫기도 유지합니다. 안내를 넘기는 입력이 뒤의 건설/채집 동작까지 실행되지 않도록 합니다.

## 주민 도착·수용
- 첫 주민 움집이 완공되면 **1명 고정**으로 등장하며, 남녀 외형은 무작위입니다. 등장만으로 자동 합류하지 않고 플레이어가 직접 수용하는 별도 퀘스트를 거칩니다.
- 이후 도착은 **1~2명 무작위**입니다. 두 명이면 남남·남녀·여여 조합 모두 가능합니다. 특정 확률은 아직 정하지 않았습니다.
- 성별로 직업·생산량에 차이를 두는 규칙은 추가하지 않습니다.
- 거주 정원 확인은 유지합니다. 도착인원 변경이 정원을 초과한 수용 허용을 뜻하지 않습니다.
- 거주 공간 부족/움집 철거 규칙과 곡식 부족 규칙을 혼동하지 않습니다. **곡식 부족으로 주민은 떠나지 않습니다.**

## 곡식 소비·작업 중단
| 상태 | 주민 1명당 곡식 소비 |
| --- | --- |
| 일을 하지 않음 | 시간당 20개 |
| 일을 함 | 시간당 30개 |

- 곡식이 부족하면 농부를 제외한 목재·석재 및 이후 다른 직업의 일을 중단합니다.
- 농부는 계속 농사하여 곡식 공급을 회복할 수 있어야 합니다.
- 굶주림 때문에 주민 삭제·이탈을 적용하지 않습니다. 향후 사냥 중 사망은 별도 미구현 아이디어입니다.
- 실제 차감 주기, 부족 판정·재개 시점, 운반 중 처리, 대기/이동 중의 소비 분류, 오프라인·배속 처리는 아직 확정하지 않았습니다. 개발 시 기존 시간 체계와 일관되게 설계하고 확정 전 수치를 임의 기입하지 않습니다.

## 기존 농사·건설 조건 유지
- 재배 준비 1분 → 성장 10분 → 100% 성숙 후 자동 수확/운반 → 전량 수확 후 준비부터 반복.
- 농장 1~4단계: 총 5/10/24/40개, 각각 1/2/3/4회로 나누어 수확.
- 농장·주민 움집 최대 개수: 촌장집 1~4단계에 따라 **1/2/3/3개**. 농장은 주민 움집 1채 이상 건설 시 해금.
- 최대 3개 4단계 농장의 시간당 약 650개는 운반 시간을 제외한 이론 상한입니다. 실제 생산은 운반·대기 때문에 더 적습니다. 작업 주민 15명 소비는 시간당 450개입니다.
- 기존 채집/운반 속도 규칙을 이번 소비 기획 때문에 변경하지 않습니다.

## 구현 전 정리할 세부사항
1. 01/02는 수량 무관 각 1회로 확정. 퀘스트 이전 선행 채집을 소급 인정할지는 미정.
2. 보상 받기 팝업의 진입 방식, 완료/수령과 다음 퀘스트 해금의 관계.
3. 저장·재접속 시 보상 중복 지급 방지와 기존 플레이어의 신규 퀘스트 이행 방식.
4. 식량 소비 차감·중단·재개·오프라인 기준.
이는 미정 세부항목이며 이미 확정된 흐름을 다시 결정하라는 뜻은 아닙니다.
