# P2 캐릭터 보완 → P3 채집·건설 연출

2026-10-30. 2D 배경과 실제 3D 캐릭터를 유지한다. P2의 아트·스킨·발 접점 보완과 실행 검토를 먼저 마친 다음 P3를 구현했다. 전체 데모나 베타 완료 판정은 아니다. 새 아트의 사용자 피드백은 열려 있다.

## P2를 먼저 마친 내용

[P2 검토 기록](stage3/p2-review.md). 원본 캐릭터의 갈색 묶은 머리, 큰 눈, 밝은 가죽옷, 꼬인 허리끈, 잎 장식을 3D 형상으로 반영했다. 팔·다리는 연속된 스킨 메시로 바꿔 관절 틈을 없앴다. 평지 보행의 발 높이와 무릎·발 회전을 계산하고 정지 시 발을 고정했다. 방향 전환·도구 부착·작업 중단 및 복귀를 유지한다. 모델과 동작은 프로젝트용으로 직접 작성했으며 외부 모델·애니메이션을 추가하지 않았다.

## P3 구현

가까운 자원에 은은한 선택 테두리·화살표를 표시하고, 도구 타격 시점에 자원이 흔들리며 재질별 작은 입자가 나온다. 실제 저장이 성공한 뒤에만 나무/돌 +1 표시가 뜬다. 건설 2초 동안 골조가 올라오고 지붕이 드러난다. 완공 시 빛의 고리와 입자를 표시하며, 오른쪽 위의 작은 보상 카드로 완성된 움집을 계속 볼 수 있다.

나무1·돌1, 종류별 1회, 채집1.2초·건설2초를 유지했다. 기존 GameState의 차감·보상·저장 로직은 변경하지 않았다. 연출은 별도 WorldFeedback에서 처리하며 취소/앱 중단 시 임시 표시를 정리한다. 저장 실패 시 획득 연출이 발생하지 않고, 연속 보상 입력에도 지급과 연출은 한 번이다.

## 남은 품질 항목과 P4

- 원본의 붓질·가죽 질감을 완전히 재현한 아트는 아니다. 새 모델의 미감은 사용자 후속 검토 대상이다.
- 평지용 발 계산이며 경사·계단/완전한 월드 공간 발 고정은 미구현. 그림자는 기존 타원 그림자로 물리 투영 그림자가 아니다.
- 실제 Android 폰·ARM GPU·발열·배터리·장시간·물리 커버/펼침 전환은 미검증.
- P4에서 채집/건설 효과음·환경음, UI 제목 대비·가독성·우측 잘림, 카메라/장면 전환을 이어서 다룬다. 새 지역·전투·성장·주민 AI는 추가하지 않았다.
