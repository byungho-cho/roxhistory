# S40200 주민 활동 초안 구현

- 합류는 기존 방문객 1~3명 단위 수용 절차를 재사용한다. 집의 빈자리가 부족하면 합류시키지 않는다.
- 상단 주민 수를 누른 뒤 주민을 선택하여 나무꾼 / 석재꾼 / 쉬기를 지정한다.
- 배정된 주민은 가까운 해당 자원까지 이동하고, 한 번 채집한 후 촌장집으로 돌아와 전달한다. 자원은 전달 시에만 증가한다.
- 자원으로 이동 / 채집 / 촌장집으로 이동 / 자원·경로 대기 상태와 운반 수량을 주민 목록에 표시한다.
- 직업을 바꾸거나 쉬기를 선택해도 운반 중인 자원은 먼저 전달한다. 직업과 운반 자원은 저장되며 재접속 후 귀환을 재개한다.
- 고갈된 자원은 동일한 자원 ID로 5~10분 뒤 유효한 새 위치를 찾아 재생성한다. 유효 위치가 없으면 대기하며, 부적절한 위치에 강제로 생성하지 않는다.
- 대상 자원이나 경로가 없으면 2초 간격으로 재탐색한다. 촌장집이 없으면 작업과 전달을 중지하고 보유 자원은 보존한다.
- 앱을 닫은 동안 채집 보상을 계산하지 않는다. 기존 고갈 타이머만 실제 시간 기준으로 이어진다.

## 기존 임시 수치 유지

한 번에 10개, 채집 1.2초, 이동 속도 181.5 월드 단위/초, 재탐색 대기 2초를 유지했다. 이는 신규 밸런스 확정이 아니라 기존 구현값을 이용한 기능 초안이다. 직업 지정은 기존 주민 패널을 사용하며 새로운 최종 UI를 확정하지 않았다.
